# 大会・外部団体・活用できるリソース

これから語学系サークルを立ち上げる人が、「どこに登録すれば大会情報が入ってくるのか」「最初の1年で現実的に狙える大会はどれか」「お金と教材はどこから調達するのか」を一度で把握するための資料です。
掲載情報はすべて公開されている一次情報（公式サイト・大学公式ページ）を実際に確認して書いていますが、確認できなかった項目には「（要確認）」を明記しています。
読む順番は、まず「最初の30日でやること」→ 資金と大学制度 → 大会、が実務的です。

> **日付の読み方**：本書に載せた日程・締切は**確認時点で公開されていた回**のものです（IIBCスピーチコンテストは2025年秋応募・2026年2月本選の回、電通育英会は2025年12月5日締切の2026年度分など）。すでに過ぎている日付は「その大会・助成が毎年おおよそこの時期に動く」という**年間サイクルの目安**として使い、応募前に必ず主催者サイトで最新回の要項を確認してください。

## 1. 最初の30日でやること

立ち上げ期に効くのは「大会に出る」ことより「情報が自動的に入ってくる状態を作る」ことです。以下は費用ゼロで、今日中に着手できます。

| 優先度 | やること | 費用 | 所要 |
|---|---|---|---|
| 最優先 | [PDML](https://www.jpdu.org/tournament/pdml)（即興型ディベートのメーリングリスト）に登録 | 無料 | 5分 |
| 高 | 大学の学生課で「サークル設立の手引き」を入手し、公認要件と申請時期を確認 | 無料 | 半日 |
| 高 | 学内の留学生支援窓口（国際交流センター）でバディ制度の募集時期を確認 | 無料 | 30分 |
| 中 | [NAFA](https://www.nafadebate.org/schedule) と [JPDU](https://www.jpdu.org/tournament/jpdu-tournament) の年間日程を自分のカレンダーに転記 | 無料 | 1時間 |
| 中 | 週次活動の教材テンプレート（後述のBBC/VOA/TED）を1本決める | 無料 | 1時間 |

**要するに**：最初の30日は「登録」と「聞き込み」に全振りしてよい。PDMLへの登録だけは今日やる。ここが国内主要大会の告知経路になっているため、これを外すと後から情報が取れません。

## 3. 英語スピーチ・弁論大会

### 伝統校主催の大会

学生英語弁論には「三大大会」と呼ばれる大隈重信杯（早稲田）・福澤杯（慶應）・天野杯（獨協）があります（この呼称自体は二次情報ベースで、公式定義ではない点に注意）。うち一次情報が確認できたのは天野杯で、[獨協大学英語会](https://dokkyoess53comi.wixsite.com/mysite/amano-trophy) が運営し、外務省・文部科学省・カナダ大使館・ブリティッシュ・カウンシルなど多数の後援がつきます。関西では同志社大学E.S.S.主催の[新島杯](https://neesimatrophy.amebaownd.com/)（1966年開始）があります。
（要確認：大隈重信杯・福澤杯の最新回の応募要項、および各大会の他大学生の出場枠・参加費は一次情報で確認できていません。）

### 新設サークルが最初に狙うべき大会：IIBC大学生英語スピーチコンテスト

TOEIC運営団体である国際ビジネスコミュニケーション協会が主催する大会で、条件が新設サークルに極めて有利です。

| 一次選考 | Word原稿＋8分以内のmp3音声をフォームでアップロード |
| 応募期間 | 2025年9月25日 10:00 〜 11月27日 15:00 |
| 本選 | 2026年2月21日（土）12:30〜17:30、赤坂インターシティAIR（東京都港区） |
| 賞 | 1位 IIBC杯＋25万円相当PC/タブレット、2位20万円相当、3位15万円相当 |

**要するに**：音源提出型の一次選考は「遠征費ゼロで全国大会に挑戦できる」という意味で、部員が数人しかいない段階の最適解です。加えて、大学単独主催のコンテスト（例：[大東文化大学学長杯](https://www.daito.ac.jp/campuslife/contest/e-speech.html)）は応募ハードルが低い反面、大学生の部が自校生限定というケースがあるため、他大学生の応募可否は必ず確認してください。

## 4. 模擬国連 — 英語で「話す理由」を作る場

ディベートよりも敷居が低く、複数人で参加できるため、サークルの合宿的な目標に向いています。

| | JUEMUN（日本大学英語模擬国連大会） | 日本模擬国連（JMUN） |
|---|---|---|
| 使用言語 | 全日程 英語 | 基本的に日本語 |
| 2026年開催 | 7月10日（金）〜12日（日）／神戸市外国語大学 | ー |
| 規模 | 約220人（うち海外大学から約20人） | 7研究会・3支部、全国約800人 |
| テーマ | Building a Gender Inclusive Society | ー |
| 起源 | 2010年 名古屋で第1回 | 1982年「模擬国連委員会」発足、2009年に現組織設立 |
| 出典 | [神戸市外大 公式ニュース](https://www.kobe-cufs.ac.jp/news/2026/23929.html) | [JMUN About](https://jmun.org/about/) |

JUEMUNには[北九州市立大学](https://www.kitakyu-u.ac.jp/news/2026/08/006786.html)など地方国公立大学からの参加報告もあり、既存の有力サークルでなくても参加余地があります（要確認：新設団体単独での参加可否・参加費は主催校への確認が必要）。

**要するに**：英語での発話量を一気に増やしたいなら JUEMUN、日本語で国際問題のリサーチ体力を鍛えたいなら JMUN、という使い分けができます。7月開催なので、4月に部員を集めて3か月準備、というスケジュールが組めます。

出典：[京都外国語大学 学生弁論大会・プレゼンテーション大会](https://www.kufs.ac.jp/about/projects/speech.html)、[第55回全国学生スペイン語プレゼン大会](https://www.kufs.ac.jp/news/detail.html?id=uKoxQTSj)、[第53回全国スペイン語弁論大会](https://www.tenri-u.ac.jp/event/42193/)

応募実務の一例として、京都外国語大学主催の全日本学生フランス語弁論大会（第50回）は、大学2〜4年生・短大2年生が対象、所属機関でフランス語を専攻または第2外国語としていることが条件で、**出場申込書に所属機関の推薦書を添えて郵送**という方式でした（申込10月上旬締切、原稿10月中旬必着）。最高賞の副賞にはパリ往復航空券が含まれます（[出典](https://www.kufs.ac.jp/news/detail.html?id=GbYOfc25)）。天理大学の大会は参加申し込みフォーム入力・先着15名、原稿はメール提出でした。

中国語には別系統で、公益社団法人日本中国友好協会主催の[全日本中国語スピーチコンテスト](https://www.j-cfa.com/project/speech/)があります。**都道府県大会に出場して一定の成績を収め、都道府県大会事務局から推薦を受ける必要がある**二段階方式で、都道府県大会は基本的にその地域に在住・在勤・在学の人が対象です。第44回全国大会は2027年1月10日（日）、東京・日中友好会館 地下大ホールで開催予定。部門はスピーチ部門と朗読部門で、「大学生の部」という区分があるかは公式ページで確認できませんでした（要確認）。

**要するに**：英語以外は「大学の推薦書」「地域予選」が関門になりがちです。つまり、教員の顧問を早期に確保しておくことが、そのまま出場資格の確保になります。1年目は京都外大系のプレゼン大会（原則として母語話者・長期滞在者は除外規定あり）を狙いやすい。

**要するに**：フランス語・ドイツ語は1回2万円超えもあるので、サークルの「全員受験」目標にすると脱退圧力になります。安価なHSK下位級やTOPIK Iを入口にし、上位級は個人判断に委ねる設計が無難です。

**要するに**：この「必ず1つに所属、でも越境自由」というルールをそのままコピーすれば、少人数でも活動が空洞化しません。言語をセクションに置き換える（英語／中国語／韓国語…）ことで多言語サークルにそのまま転用できます。

## 8. お金 — 学内補助金と外部助成

### 学内補助金（早稲田大学の例）

[早稲田大学の課外活動補助金](https://www.waseda.jp/inst/student/circle/procedures/subsidiary)は公認サークルが対象で、30万円／15万円／10万円の3コース制。補助対象は直接経費のみで、**食費・宿泊費・交通費・衣装代は対象外**です。申請は通常3月または9月、結果発表は6月。

## 9. 大学の制度を使い倒す

### 公認サークル化のハードル（大学差が大きい）

| 大学 | 主な要件 |
|---|---|
| 早稲田大学 | 早大生のみで21人以上・2学部以上／サークル名での活動実績1年以上／領収書添付の1年分の会計報告／会長・幹事長・副幹事長・会計を各1名／会長は専任教員・特任教授・任期付教授/准教授・専任職員のいずれか（兼務上限2サークル） |
| 明治大学 | 毎年度の継続手続が必須。期日までに未提出だと「公認取消」となる場合あり。2026年度締切5月29日。学生団体役員届・部員名簿・活動予定表・誓約書・部規約・会計報告書をオンライン申請 |
| 明治学院大学 | まず「設立準備団体」として申請 → 1年間活動 → あらためて公認申請。申請時期は毎年4月 |

出典：[早稲田大学 公認サークルになるには？](https://www.waseda.jp/inst/student/circle/howto)、[明治大学 各種必要手続](https://www.meiji.ac.jp/campus/circle/6t5h7p00000g8e3l.html)、[明治学院大学 FAQ](https://www.meijigakuin.ac.jp/faq/00115.html)

### 留学生バディ制度

[京都産業大学のバディ制度](https://www.kyoto-su.ac.jp/international/dekiru/tutor/)では、①毎週1回のバディランチ ②バディレポート提出 ③イベント企画（歓迎会、花見、京都三大祭見学、伝統工芸体験など）が活動内容です。募集案内は春学期7月頃・秋学期12月頃。同種の制度は多くの大学に存在します。

### 派遣プログラム・合宿

- [関西学院大学 ACUCA Student Camp 2026](https://ciec.kwansei.ac.jp/information/news/acuca-student-camp-2026.html)：台湾での国際学生会議。応募締切4/28 → 書類選考 → 面接（5/9）→ 参加者発表（5/13）
- [ブリティッシュヒルズ English Camp](https://www.british-hills.co.jp/edu/private/englishcamp/)：福島県。館内公用語が英語の合宿型研修で、大学生・短大生・専門学校生向けの University & College コースあり（料金は当該ページに非掲載）

**要するに**：公認化は「人数」より「1年分の実績と会計記録」で詰まります。多くの大学では設立準備団体などの助走期間が設けられているので、初年度は公認を焦らず、記録づくりに集中するのが正解です。並行して留学生バディに部員を送り込めば、「実際に話す相手」を大学の予算で確保できます。
