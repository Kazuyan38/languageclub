# 国内大学の英語サークル・部活の実例集

国内25団体前後の英語サークル・ESS（English Speaking Society）について、大学公式サイトや団体公式サイトで公開されている**部員数・活動曜日・会費・組織構成**を集め、規模別・運営スタイル別に整理した資料です。
これからサークルを立ち上げる人が、「何人でどんな形なら成立するのか」「会費はいくらに設定すべきか」「公認を取りに行くべきか」を、実在する団体のデータをもとに判断できるようにすることを目的にしています。
数値はすべて出典付きで示し、裏取りできなかったものは「（要確認）」と明記しています。

---

## 1. まず押さえるべき3つの設計軸

集めたデータを並べると、英語サークルの設計は次の3つの軸でほぼ決まります。

1. **規模**（6名〜120名超）── 規模がセクション制の有無を決め、セクション制の有無が会費と活動量を決める
2. **時間帯**（昼休み / 放課後 / 土曜）── 学部の時間割との相性で決まる。ここを間違えると人数が集まらない
3. **所属形態**（公認 / 未公認 / インカレ）── 部室・補助金・新歓の可否に直結する

**要するにこうすればよい**：最初に決めるのは「規模」ではなく「時間帯」です。規模はコントロールできませんが、時間帯は自分で決められ、しかも集まる人数を最も強く規定します。昼休み30分から始めた団体（日本女子大・名寄市立大）も、週5日開ける団体（早稲田WESA）も、どちらも実在します。

## 3. 活動内容の設計：セクション制か、フリートーク型か

規模によって活動の組み方がはっきり分かれます。

### 20名未満：セクションを作らない

[金城学院大学ESS](https://www.kinjo-u.ac.jp/ja/campus-life/club/skill/02/)は主活動が「英語でおしゃべり」で、ネイティブ講師との会話練習とハロウィン・クリスマスのパーティーが年間行事です。[愛媛大学E.S.S.](https://www.ehime-u.ac.jp/en/circle/e-s-s-english-speaking-society/)も英語ゲーム・会話練習・留学生との交流・異文化ディスカッションで、部門分けはありません。[名寄市立大学のENGLISHLUNCH](https://www.nayoro.ac.jp/life_career/life/circle_activity/English.html)に至っては、昼食をとりながら留学生と話すだけの構成です。

### 30〜60名：年間イベントカレンダーで骨格を作る

セクションを作るには人数が足りない一方、毎回フリートークだと飽きられる帯です。この規模の団体は「年間行事」で変化をつけています。[関西大学 英語研究部](https://www.kansai-u.ac.jp/gakusei/activity/club/gakken02.html)の年間カレンダーはそのまま流用できる完成度です。

| 月 | 行事 |
|---|---|
| 4〜5月 | 新歓 |
| 5月 | 入部式 |
| 6月 | 関関戦（関西学院大学との定期戦） |
| 7月 | 遠足 |
| 8月 | 合宿 |
| 10月 | ハロウィンパーティー |
| 11月 | 学祭・シナリオコンテスト |
| 12月 | スピーチ大会 |
| 3月 | 花見 |

### 70名以上：セクション（部門）制に移行する

| 団体 | セクション構成 |
|---|---|
| [立教大学英語会](https://www2.rikkyo.ac.jp/web/z4000095/NewFolder/information.html) | Debate / Discussion / Drama / Speech の4セミナー＋全体活動（キャンプ、半期5回のEP活動、前期月1回のGuide活動）の2階層 |
| [法政大学 英語研究会ESS](https://www.hosei.ac.jp/info/article-20211014141726/?auth=9abbb458a78210eb174f4bdd385bcf54) | ドラマ / スピーチ / ディスカッション / ディベート / リタラチャー の5セクション |
| [山口大学 Y.U.E.S.S.](https://yuess.jimdofree.com/about-us/) | Debate / Discussion / Drama / I.S. / Speech の5セクション |
| [青山学院大学 E.S.S.](https://agu-ess.com/section/) | Speech / Discussion / Debate / Pronunciation の4セクション |
| [東京大学 E.S.S.](https://ut-ess.com/) | ドラマ / スピーチ / ディスカッション の3セクション |
| [早稲田大学英語会 W.E.S.S.](https://wesswaseda.com/) | 1・2年会は5つのHM（Home Meeting）、3年会はSpeech / Debate / Drama の各Section |
| [南山大学 E.S.S.](https://office.nanzan-u.ac.jp/student-services/clubs/clublist/bunkakei-kokusai/000145.html) | ディベート部門 / ガイド部門 の2部門 |

**要するにこうすればよい**：セクション名は「Speech・Discussion・Debate・Drama」の4つがほぼ業界標準で、これに各校が独自の1つ（法政の「リタラチャー」、青学の「Pronunciation」、南山の「ガイド」、山口の「I.S.」）を足す形です。立ち上げ時はセクションを作らず、まず**Discussion一本**で始め、人が増えた段階で分けるのが実データに沿った順序です。参考までに、[青山学院大学のDiscussion Section](https://agu-ess.com/section/)は1グループ6〜7人で運用しています。この人数が議論が回る最小単位の目安になります。

## 6. 公認・未公認・インカレの選び方

### 公認要件の実例（早稲田大学）

[早稲田大学 学生生活課](https://www.waseda.jp/inst/student/circle/howto)は要件を明示しています。

| 項目 | 要件 |
|---|---|
| 人数 | 早大生のみで21人以上 |
| 構成 | 2学部以上にまたがること |
| 実績 | そのサークル名で学内外の活動実績が1年以上 |
| 会計 | 領収証を添付した1年間以上の会計報告（宛名はサークル名、使途明記） |
| 役員 | 会長（専任教員等）・幹事長・副幹事長・会計を各1人 |
| 三役の制約 | 三役内の兼任不可、他公認サークル三役との兼任不可、3年生以下が最低1名 |

公認化予定がなくても「登録（未公認）サークル」として大学に情報登録できる制度がある点も明記されています。

### 手続きの流れ（大学ごとに異なる）

| 大学 | 未公認の扱い | 公認までの経路 |
|---|---|---|
| [早稲田大学](https://www.waseda.jp/inst/student/circle/howto) | 「登録（未公認）」として登録可能 | 21人以上・2学部以上・実績1年以上・会計報告 |
| [明治学院大学](https://www.meijigakuin.ac.jp/faq/00115.html) | 届出不要 | 「設立準備団体」として申請 → 1年間活動 → 公認申請（受付は毎年4月） |
| [日本女子大学](https://www.jwu.ac.jp/unv/seg_student/circle/index.html) | — | 公認サークルは約70団体。施設利用・保険適用・援助金の特典を明示（設立要件はページ上に記載なし） |

### 公認のメリットとインカレという選択肢

[早稲田ウィークリーの特集記事](https://www.waseda.jp/inst/weekly/feature/2014/06/16/21521/?lng=en)によれば、公認サークルは学生会館の部室・会議室を利用でき、課外活動補助金を申請でき、学内掲示板やイベント、新歓活動で優遇されます（2014年の記事のため金額等は要確認）。

一方、[Paddy Fielders' Tea Party](https://www.waseda.jp/inst/weekly/circleguide/detail/?id=3487&lng=en)は早稲田大学の公認を持ちながら、立教・明治・日本女子・家政・聖路加看護・東京女子医科などから部員が集まる**インカレ型**で、部員60名を維持しています。幹事校を1つ持って学生会館を使いつつ、募集母集団を大幅に広げる形です。対照的に[慶應K.E.S.S.](https://circle.info-jukusei.com/academic/%e8%8b%b1%e8%aa%9e%e6%9c%83%ef%bc%88k-e-s-s-%ef%bc%89/)は文化団体連盟の公認団体として大学内で完結しています。中間形態として、南山大学E.S.S.のディベート部門は「曜日によって練習が開催される大学が違います」とあり、単一大学団体でも練習単位では他大学と合同になります。

**要するにこうすればよい**：明治学院大の「設立準備団体 → 1年 → 公認申請」、早稲田の「登録（未公認） → 実績1年 → 公認申請」のように、**1年の実績期間を挟むのが標準**です。したがって初年度は公認を諦め、(1) 名称を固定する、(2) 領収証を団体名宛でもらって会計記録を残す、(3) 活動記録を写真とログで残す、の3点だけを徹底してください。この3点が翌年の公認申請書類にそのまま化けます。なお、非公認のまま運営されている英語サークルの実例は、大学公式サイトが公認団体しか掲載しない構造上、今回は特定できませんでした（要確認）。

## 7. 全国ネットワーク（連盟）という外部資源

英語サークルには他ジャンルにない特徴があります。**単一大学の団体でも、連盟経由で全国の他大学と大会・合同練習ができる**という点です。

[J.U.E.L.（全日本学生英語会連盟）](https://kuel.client.jp/juel.html)は1979年1月1日設立で、以下の地区連盟が加盟しています。

| 地区 | 連盟名 |
|---|---|
| 北海道 | 北海道学生英語研究会連盟（H.E.S.S.L.） |
| 東北 | 全東北英語会連盟（A.T.E.L.） |
| 関東 | 関東学生英語会連盟（K.U.E.L.） |
| 関西 | 関西英語会連盟（K.E.S.S.A.） |
| 中国 | 中国地区大学E.S.S.連盟（L.E.S.S.C.） |
| 福岡 | 福岡学生英語連盟（F.S.E.A.） |

K.U.E.L.は1971年1月1日設立（設立決定は1970年12月23日）で、2021年4月2日時点の加盟は34団体です（[K.U.E.L.について](https://2021kuelnego.wixsite.com/mysite/k-u-e-l-%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6)で確認。ただし同ページは2021年度版のため現況は要確認）。「発足時30大学32団体」「2012年5月時点で46団体・約3,300名」という数値は同ページ本文には記載がなく、検索結果由来のため**要確認**です。

なお、地区連盟の名称には紛らわしい2系統があります。J.U.E.L.の関西地区加盟団体は**K.E.S.S.A.（関西英語会連盟）**ですが、別に**K.I.E.F.（関西地区学生英語会連盟）**という団体も存在し、[06-competitions-and-resources.md](./06-competitions-and-resources.md) §7で扱っています。両者の関係（同一団体の別称か、別組織か）は公開情報からは確定できませんでした（要確認）。関西の団体に問い合わせる際は、どちらを指しているかを最初に確認してください。

実例としても、[日本女子大学E.S.S.](https://www.jwu.ac.jp/unv/seg_student/circle/ess.html)は他大学との提携は「なし」としつつ他大学ESS主催の大会に参加し、[名古屋工業大学E.S.S.](https://www.nitech.ac.jp/campus/club/ess.html)は中部ディベート連盟にリンクし、[岡山大学E・S・S](https://support.st.okayama-u.ac.jp/clubs/club/18)は2022〜2023年にレスクスピーチコンテストや「きのこ杯」で入賞しています。

**要するにこうすればよい**：新設団体は自前で対外イベントを企画する必要がありません。地区連盟の大会に「出る側」で参加するだけで、部員の目標設定・他大学との交流・広報実績の3つが同時に手に入ります。設立初年度から地区連盟に問い合わせておく価値があります。
