# 多言語サークル 立ち上げチェックリスト

まだ何も始めていない段階から、初回活動を開き、新歓を回し、次代に引き継ぐまでを、順番どおりに潰していくための実行リストです。
背景となる調査結果（実例・数値・制度の根拠）は本リポジトリの[01](./01-club-types-and-activities.md)〜[06](./06-competitions-and-resources.md)にあります。ここでは**手を動かす順番**だけを書き、根拠が要る箇所は各ドキュメントへリンクします。

使い方は単純です。フェーズ0から順に上から潰してください。フェーズをまたいで先回りしてよいのは「学生課への質問」と「顧問依頼」の2つだけです。この2つは締切と兼務上限があり、遅れると1年待ちになります（→[サークルの立ち上げ・公認化・運営の実務](./04-founding-and-operations.md)）。

---

## 最初に決めるべき7つの問い

初回のミーティングで、この7項目を紙に書いて確定させてください。ここが曖昧なままSNSを作ると、新歓期に「で、何をするサークルなの？」に答えられません。

| # | 問い | 選択肢 | トレードオフ | 迷ったら |
|---|---|---|---|---|
| 1 | 扱う言語 | ①英語一本 ②英語＋1言語 ③多言語（常設2〜3言語＋変動） | 英語一本は母語話者・教材・大会が最も豊富で運営が軽い。多言語は差別化できるが、言語ごとに話者を確保できず崩壊しやすい | ③の「常設2〜3言語だけ宣言、他は当日のスタッフ次第」（筑波大方式）。開けない日が失敗にならない |
| 2 | 対象レベル | ①初心者歓迎 ②中級以上 ③レベル分けなしの混在 | 初心者歓迎は母集団が最大だが上級者が退屈する。中級以上は質が保てるが立ち上げ期は人が集まらない | ①。ただし「英語が苦手でも大丈夫」ではなく「上級生も未経験から始めた」という具体的事実を書く |
| 3 | 活動頻度 | ①昼休み20〜30分×週1〜2 ②放課後1.5〜2時間×週1〜2 ③固定枠3つから2回選択制 | 昼休み型は兼部されやすく離脱も少ないが深まらない。放課後型は密度が出るが運営者が先に消耗する | ①で開始。定着後に夕方枠を増設して二枠併用へ |
| 4 | 規模感 | ①10名前後 ②20〜30名 ③50名以上 | 10名前後でも大学公式に掲載され継続する団体は実在する。20名超からセクション制の検討圏、公認人数要件（大学により5〜21名）にも関わる | ②を1年目の目標に。10名で始めることを恥じない |
| 5 | 公認を目指すか | ①初年度から申請 ②1年活動してから申請 ③非公認のまま | 公認は部室・補助金・新歓ブース、そして**保険**（学研災）が付く。非公認は身軽だが事故時に無保険になる | ②。ただし「届出／登録」だけは初年度に済ませる |
| 6 | 会費の有無 | ①0円 ②年1,000円前後 ③年3,000円以上 | 0円はそのまま競争力になる（学生のサークル支出意欲はコロナ前水準に未回復）。会費が高い団体は公演・遠征を伴う | ①か②。合宿・遠征・大会は都度実費徴収 |
| 7 | オンライン/対面 | ①対面のみ ②対面＋オンライン併用 ③オンライン中心 | 対面は定着率が高いが教室確保が要る。オンラインは場所コストゼロだが、課外活動として認められるか・保険対象かが大学ごとに不明 | ①で開始し、テスト期・長期休みだけ②。③は事前に学生課へ確認 |

各項目の判断材料は[サークルの類型と活動内容](./01-club-types-and-activities.md)と[国内大学の英語サークル・部活の実例集](./02-university-case-studies.md)に実数付きで整理しています。

## フェーズ0 構想を固める

**目安時期**：始めようと思った日から2週間以内（4月新歓を狙うなら遅くとも前年11月）
**このフェーズのゴール**：7つの問いに答えが埋まり、団体名が確定していること

- [ ] 上記「7つの問い」に暫定回答を書き、発起人全員で読み合わせる
- [ ] 団体名を確定する。**以後は絶対に変えない**（公認要件の「同一名称で1年以上」に直結）
- [ ] 自大学の学生課ページで「設立申請の締切」「公認までの最短年数」「人数要件」「必要書類」の4点を確認する
- [ ] 学内に競合する既存団体（ESS・国際交流会・語学系）がないか一覧で確認し、あるなら差別化点を1行で書く
- [ ] 「やらないこと」を3つ書き出す（例：合宿はやらない／全員参加の必須活動は作らない／年間公演はやらない）
- [ ] 年間行事を**2つだけ**仮置きする（春の内部イベント／秋の学祭企画）
- [ ] 活動しない期間を先に宣言する（試験期・長期休暇）。これがないと試験期に自然消滅する
- [ ] 想定する1回の基本単位を「6〜7人＋ファシリテーター1人」と決めておく

## フェーズ1 発起人と初期メンバーを集める

**目安時期**：フェーズ0の直後から1か月
**このフェーズのゴール**：発起人5名＋顧問1名が揃い、規約の初稿ができていること

- [ ] 発起人を5名集める（多くの大学の最低ラインが5名前後。学部・学年をばらけさせると公認要件を同時に満たせる）
- [ ] 顧問候補の教員をリストアップし、**就任承諾書の様式を持参して**依頼する（兼務上限があり早い者勝ち。無報酬・任期2年が典型）
- [ ] 役員を決める（代表／副代表／会計2名／広報）。**会計は必ず代表と別人**にする
- [ ] 後掲テンプレートをベースに規約（会則）の初稿を作る
- [ ] 国際センター／留学生支援室に足を運び、「既存の留学生向けイベントを手伝わせてほしい」と申し出る
- [ ] 国別留学生会（中国・韓国・台湾など）の連絡先を調べ、スタッフ役の相談ルートを1本作る
- [ ] 団体名義の銀行口座を開設する
- [ ] 収支簿（スプレッドシート）と領収書貼付台紙を用意し、1円目の支出から記録を始める
- [ ] 活動記録テンプレ（日付／場所／参加者／内容／写真）を作り、共有ドライブに置く

母語話者の確保を個人の人脈で解こうとしないこと。再現性のあるルートは[多言語・国際交流系サークルの実例と運営](./03-multilingual-and-exchange.md)にまとめてあります。

## フェーズ2 大学への申請・公認化

**目安時期**：フェーズ1と並行、締切の1か月前まで
**このフェーズのゴール**：最低でも「届出／登録団体」の地位を得て、教室が予約できる状態になること

- [ ] 提出書類を揃える（設立届／規約／名簿／顧問就任承諾書／活動計画書／収支予算書が典型）
- [ ] 締切に間に合わないと判明したら、迷わず**未公認で先に活動を始める二段階ルート**に切り替える
- [ ] 「登録（未公認）」制度があるか確認し、あれば必ず登録する（教室貸出が使えることが多い）
- [ ] 学研災の適用範囲を学生課で確認する。**合宿・遠征・イベントの前に届出を済ませる**
- [ ] 新歓期の禁止事項（ビラの配布方法・エリア規制・立て看板の重り規定）を印刷して手元に置く
- [ ] 課外活動の禁止日・活動可能時間帯（例：原則8:00〜20:00）を確認し、活動枠がその範囲に収まっているか照合する
- [ ] 学内補助金の申請時期とコース、対象外経費（食費・宿泊費・交通費・衣装代は典型的に対象外）を確認する
- [ ] 教室の定期予約を取る（部室は活動報告を出し続けた先にあるものと割り切る）
- [ ] 大学名の使用や学外イベント開催に事前承認が要るかを確認する

条文レベルの比較（人数要件は大学により5〜21名、7倍の開き）は[サークルの立ち上げ・公認化・運営の実務](./04-founding-and-operations.md)を参照してください。

## フェーズ2.5 安全・配慮・個人情報の運用を先に決める

**目安時期**：初回活動を開く前（フェーズ3と同時進行）
**このフェーズのゴール**：トラブルが起きたときの「誰に・どうやって」が紙に書いてあること

> **注意**：本節は大学公式の一次情報が乏しい領域です（学生団体向けのハラスメント防止ガイドラインや名簿管理の学内指針は、[04](./04-founding-and-operations.md) §8の調査でも本文を取得できませんでした）。以下は他ドキュメントの制度情報から逆算した**運用提案**であり、出典付きの実例ではありません。自大学のハラスメント相談窓口・個人情報取扱規程を必ず確認し、そちらを優先してください。

### トラブル対応の窓口を作る

- [ ] 大学のハラスメント相談窓口・学生相談室の連絡先を調べ、規約または運用メモに書いておく
- [ ] サークル内の相談担当を**2名（できれば性別を分ける）**決め、代表とは別人にする
- [ ] 匿名で送れる意見・相談フォーム（Googleフォーム）を作り、回答先を相談担当のみに限定する
- [ ] 「サークル内でのトラブル・事故は直ちに顧問に報告する」を役員の義務として明文化する（明治大学が公認サークル役員に課している義務と同趣旨。→[04](./04-founding-and-operations.md) §8）
- [ ] 飲み会は「参加自由・未成年に飲ませない・帰宅手段を確保」を毎回口頭で宣言する。規約の飲酒条項（会則テンプレ第12条）と対で運用する

### 多言語・国際交流サークル特有の配慮

英語系サークルと違い、多言語サークルには宗教・食習慣・言語背景の異なる参加者が同時に来ます。これは事前準備で吸収できます。

- [ ] 飲食を伴う企画では、**ハラール／ベジタリアン／アルコール不使用**の選択肢を必ず1つ用意し、告知文に明記する
- [ ] 学内の礼拝スペースの場所と利用方法を調べておく（東北大学のTUMCAのように、礼拝所やハラルフードの相談を担う学生団体がある大学もある。→[03](./03-multilingual-and-exchange.md) §6）
- [ ] 会場のバリアフリー経路（エレベーター・多目的トイレ）を確認し、告知文にアクセス情報を1行入れる
- [ ] 「特定の国・地域の政治や宗教について団体としての立場を取らない」を規約または運用メモに書く（明治大学は「宗教的活動」「営利活動」を公認不可事由に挙げている。→[04](./04-founding-and-operations.md) §8）
- [ ] 参加者の国籍・出身を推測で紹介しない、代表して意見を言わせない、をファシリテーターの共通ルールにする

### 個人情報と写真

- [ ] 名簿に集める項目を**必要最小限**（氏名・所属・連絡先1つ）に絞り、集める理由を入会時に説明する
- [ ] 名簿は共有ドライブの限定公開フォルダに置き、閲覧権限を役員のみにする。個人のPC・LINEトークに置かない
- [ ] 写真の公開可否を入会時に一度確認し、NGの人を名簿に記録する。集合写真は撮影時にも口頭で確認する
- [ ] 広報アカウントは個人アカウントと分け、**投稿前に必ず2人目がチェックする**
- [ ] 卒業・退会時の名簿データの扱い（削除するか、OB名簿に移すか）を先に決めておく

### オンライン運営（Discord／LINEオープンチャット）

- [ ] サーバー／グループの管理者を**必ず2名以上**にする（1人だと引き継ぎ時に復旧不能になる）
- [ ] 招待リンクは有効期限付きにするか、参加時に一言確認するフローを挟む（公開リンクの放置は外部からの勧誘・スパム流入経路になる）
- [ ] チャンネルは「お知らせ（運営のみ投稿）」「雑談」「言語別」の3種から始める。最初から作り込まない
- [ ] 荒らし・不適切投稿があった場合の対応（削除→警告→退出処理）と、その判断を誰がするかを決めておく
- [ ] オンライン活動が課外活動として認められるか・学研災の対象になるかは**大学差があり一次情報を確認できていない**。合宿・遠征と同様、事前に学生課へ確認する

### 初年度予算の費目テンプレート

金額の全国相場を示す一次データは見つかりませんでした（[02](./02-university-case-studies.md) §9、[04](./04-founding-and-operations.md) §6）。ただし**費目**は先に決められます。収支簿の勘定科目としてそのまま使ってください。

| 区分 | 費目 | 初年度の扱い |
|---|---|---|
| 収入 | 部費（年0〜1,000円想定） | 徴収は5月以降。4月は無料の体験期間 |
| 収入 | 学内補助金 | 公認後。給付率は半額が典型（早稲田） |
| 収入 | 都度実費徴収（合宿・遠征・大会） | 参加者からその都度。部費に含めない |
| 支出 | 印刷費（ビラ・ポスター・名札） | 新歓期に集中。最大の初期費用になりやすい |
| 支出 | 教材・書籍・コピー代 | BBC/VOA/TED等の無料教材を軸にすれば圧縮できる（[06](./06-competitions-and-resources.md) §10） |
| 支出 | 大会参加費・交通費 | 補助金の対象外になりやすい（交通費は典型的に対象外） |
| 支出 | 学祭企画費（衣装・小道具） | 衣装代・小道具代も補助金の対象外が典型 |
| 支出 | 飲食費（交流会） | **補助金の対象外**。最初から自己負担で設計する |
| 支出 | 検定の団体受験 | HSK下位級・TOPIK Iなど安価なものに限定（[06](./06-competitions-and-resources.md) §6） |

### 続けるか畳むかの判断基準を先に書く

- [ ] 「◯月末までに定例参加者が◯名を下回ったら、活動頻度を落とす／既存団体と合流する」という撤退・縮小のラインを、活動開始前に紙に書いておく
- [ ] 学内に競合する既存団体（ESS・国際交流会）がある場合、差別化ではなく**合流**が合理的なケースを想定しておく
- [ ] 解散する場合の手続き（大学への団体解散届、口座の解約、残余財産の扱い）を規約または運用メモに一行入れておく

## フェーズ3 初回活動の設計

**目安時期**：申請と並行、初回開催の2週間前から
**このフェーズのゴール**：進行台本が完成し、当日その紙どおりに進めれば成立する状態になること

- [ ] 曜日・時間・場所を固定し、以後変えない
- [ ] 常設言語（2〜3）と変動言語を告知文で分けて書く
- [ ] 初心者テーブル（またはビギナーグループ）を必ず1つ用意する
- [ ] 進行役を決める。輪番か固定かを規約または運用メモに明文化する
- [ ] 教材を1本に決める（BBC 6 Minute English などを毎週1本回すだけで定例は成立する）
- [ ] 「今週のテーマ・使う言語・進行形式」を前日までに告知するテンプレを作る
- [ ] 90分（または30分）のタイムテーブルを紙に印刷して当日持参する
- [ ] 「日本語禁止ルール」を採るかどうかを決める。初心者歓迎を掲げるなら採らない
- [ ] 終了後5分で振り返りを行い、次回のテーマをその場で決めて即告知する

### 初回活動の90分タイムテーブル案

放課後枠（例：17:00〜18:30）で、参加者12〜14名・2グループを想定した進行です。昼休み30分枠でやる場合は、②③⑥だけを残して各5〜10分に圧縮してください。

> **これは実例ではなく本書の提案です。** 分単位のタイムテーブルを公開している大学サークルの公式ページは、今回の調査では見つかりませんでした（[01 §6](./01-club-types-and-activities.md)参照）。ただし「1グループ6〜7人＋ファシリテーター1人」という基本単位だけは青山学院大学E.S.S.・桜美林大学の実運用で確認できた実数なので、そこを崩さずに時間配分だけ自分の環境に合わせて調整してください。

| 時刻 | 分 | 内容 | 進行のポイント |
|---|---|---|---|
| 17:00 | 5 | 受付・名札書き | 名前とローマ字表記だけ。所属や学年は書かせない |
| 17:05 | 5 | オープニング | 団体の趣旨・今日の流れ・「途中入退室自由」を宣言 |
| 17:10 | 10 | アイスブレイク（全体） | 2文自己紹介を全員1周。制限時間を切る |
| 17:20 | 25 | メイントーク（6〜7人×2グループ） | 事前告知したテーマ1本。ファシリテーターが言い回しを相手に合わせる |
| 17:45 | 5 | 休憩・グループ入れ替え | ここで必ず組み替える。同じ人としか話さない事故を防ぐ |
| 17:50 | 25 | フリートーク／初心者テーブル | 話せる人は自由に、不安な人は初心者テーブルへ誘導 |
| 18:15 | 10 | 共有（全体） | 各グループ1分ずつ、今日出た表現を1つ発表 |
| 18:25 | 5 | クロージング | 次回の日時・テーマ・使う言語をその場で告知し、連絡先QRを掲示 |

進行の型と「1グループ6〜7人＋ファシリテーター1人」という基本単位の根拠は[サークルの類型と活動内容](./01-club-types-and-activities.md)にあります。

## フェーズ4 新歓と拡大

**目安時期**：新歓集中期の2か月前（＝2月）から5月末まで
**このフェーズのゴール**：入会導線が1タップで完結し、5月末に正式入会者が確定していること

- [ ] 2月中にX・Instagramを開設し、プロフィールと固定ポストを整える
- [ ] 3月から週2〜3回の定期投稿を始める（Xで新規到達、Instagramのストーリーズ＋ハイライトで雰囲気）
- [ ] 着地点をLINEオープンチャットかDiscordにし、**入会フォームを挟まない**
- [ ] 「無料・選考なし・全員参加必須なし・掛け持ち可」を規約と募集文の両方に明記する
- [ ] 大学公式のサークル紹介サイト／新歓実行委員会の企画枠に応募する（無料の一次露出）
- [ ] ビラを入稿する（団体名・活動内容・曜日時間場所・QRを必ず記載。手渡し限定などのルールを守る）
- [ ] 新歓集中期（多くの大学で4/1〜4/4前後、実働20〜30時間）に人員シフトを組む
- [ ] 4月中に体験会を複数回開く。説明会ではなく「実際に話す場」にする
- [ ] 4月は完全無料の体験期間とし、正式入会と会費徴収は5月以降にする
- [ ] 新入部員の最初の1か月に、自己紹介・少人数座談会・既存メンバーとの1対1接続を意図的に入れる
- [ ] 募集を通年で開けたままにし、秋にも告知を打つ（秋加入が新規の2〜5割を占める団体が実在する）

新歓の日程設計・SNSの役割分担・離脱要因の分析は[新歓・勧誘・広報とメンバー定着](./05-recruitment-and-promotion.md)に詳述しています。

## フェーズ5 継続と引き継ぎ

**目安時期**：初回活動の3か月後から、毎年度末まで
**このフェーズのゴール**：代表が交代しても運営が止まらず、翌年の公認申請・助成応募の材料が揃っていること

- [ ] 全体をつなぐ短い定例枠（週1回の昼休み15分でも可）を1つだけ必須にする
- [ ] 人数が20〜30名を超え、関心が明確に分かれてからセクション制を検討する（分けたら全体活動を必ず併設）
- [ ] セクションは言語ではなく**活動形式**（議論する／演じる／話す）で切る
- [ ] 対外イベントは自作せず、地区連盟や既存大会に「出る側」で参加する
- [ ] 音源提出型のスピーチコンテストなど、遠征費ゼロで挑める大会を1つ年間目標に置く
- [ ] 学祭企画は短編語劇（日本語字幕付き）を軸にする。多言語スピーチ大会より集客できる
- [ ] 年度末に会計報告（収支簿・決算書・予算書）を作り、代表と会計の双方で確認印を押す
- [ ] 引き継ぎは会ではなく**チェックリスト**で行う：①口座名義変更 ②役員交代届 ③SNS・メール・共有ドライブの管理者権限移譲 ④規約と会計書類の所在共有 ⑤顧問への新代表紹介
- [ ] ①と③は**卒業式前に必ず終わらせる**（連絡が取れなくなると復旧不能）
- [ ] 2年目に外部助成へ応募する（多くが「2年以上の活動実績」を要件にする）

大会カレンダー・助成金・無料教材の一覧は[大会・外部団体・活用できるリソース](./06-competitions-and-resources.md)にあります。

## 会則（規約）骨子テンプレート

一橋大学が公開している規約例（全12条＋付則）を骨子に、信州大学が求める記載事項（入退会手続き・部費）を足した最小構成です。**ゼロから書かないこと。**以下をコピーし、`〇〇` を差し替え、第5条を自団体の実態に書き換え、第11条を自大学の飲酒ルールの正式名称に置き換えれば、初稿は1時間でできます。

```text
〇〇大学 〇〇〇〇会 会則

第1条（名称）
　本会は、〇〇〇〇会（以下「本会」という）と称する。

第2条（所在）
　本会は、本会の目的に賛同し自発的に参加する者で組織し、本部を〇〇大学に置く。

第3条（趣旨）
　本会は、多言語による日常的な会話および文化交流の機会を学内に常設することを趣旨とする。

第4条（目的）
　本会は、前条の活動を通じて会員相互の親睦を図り、語学運用能力および異文化理解の向上に資することを目的とする。

第5条（活動）
　本会は、前条の目的を達成するため、次の活動を行う。
　（1）定例活動　毎週〇曜日 〇〇:〇〇〜〇〇:〇〇、〇〇教室
　（2）常設言語は〇〇語・〇〇語とし、その他の言語は当日の運営体制に応じて開設する
　（3）学園祭における企画の実施
　（4）学外の大会・コンテスト等への参加
　（5）その他、本会の目的に適うと認める活動

第6条（会員）
　1　本会の目的に賛同する〇〇大学の学生は、所定の方法により入会を申し出ることで会員となる。入会に際して選考は行わない。
　2　会員は、代表者への申し出により、いつでも退会することができる。
　3　他団体との兼部を認める。また、すべての活動への参加を義務づけない。

第7条（組織）
　1　本会に、代表1名、副代表1名以上、会計2名、広報担当若干名を置く。
　2　会計は代表を兼ねることができない。
　3　本会に顧問を置き、教員の立場から助言と指導を与える。

第8条（議決）
　本会に部会を置き、企画運営に関する事項を審議し決定する。部会は出席会員の過半数をもって議決する。

第9条（会計）
　1　本会の運営経費は、部費および本会の趣旨に賛同する個人・団体からの援助金等をもって充てる。
　2　部費は年額〇〇円とし、〇月に徴収する。合宿・遠征・大会参加に係る費用は都度実費を徴収する。
　3　会計年度は毎年4月1日に始まり、翌年3月31日に終わる。
　4　会計は、本会名義の口座により収支を管理し、年度末に収支決算書を作成して部会の承認を受ける。

第10条（除名）
　本会の目的に反する行為を行った会員は、部会の議決により除名し、または期間を定めて活動への参加を制限することができる。

第11条（事故防止の義務）
　会員は、事故を未然に防ぐ能力の習得に努め、常に最善の努力をする。不測の事態が生じた場合は人命救助を最優先とする。

第12条（飲酒）
　会員は「〇〇大学 学生の飲酒に関する基本原則」を遵守し、未成年者に飲酒をさせてはならない。

第13条（改廃）
　本会則の改廃は、部会の承認を受けなければならない。

付則
　本会則は、〇〇年〇月〇日から施行する。
```

大学によっては「昨年度までの活動実績」を会則内または別紙に記載するよう求められます。提出前に必ず自大学の様式指示を確認してください。
