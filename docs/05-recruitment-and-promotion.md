# 新歓・勧誘・広報とメンバー定着

これからサークルを立ち上げる人に向けて、新歓の日程設計・大学のルール・広報チャネルの選び方・入会導線・定着施策を、大学公式ページと全国調査で裏取りした情報だけを使って整理した。
「4月の4日間で何が決まるのか」「団体設立にどれだけリードタイムが要るのか」「どうすれば人が辞めないのか」の3点に答えることを目的にしている。
数値と固有名詞はすべて出典リンク付きで示し、裏が取れなかったものは末尾の「要確認」にまとめた。

---

## 1. 前提：まず市場の数字を押さえる

新歓の設計は「1年生の需要がどれだけあるか」を知るところから始まる。

| 指標 | 数値 | 出典 |
| --- | --- | --- |
| サークル所属率（全体） | 63.8%（前年比 +3.6pt） | [第60回学生生活実態調査](https://www.univcoop.or.jp/vision/vision_493.html) |
| サークル所属率（1年生） | 80.0%（前年比 +2.1pt） | 同上 |
| 調査規模（第60回） | 2024年10〜11月・11,590人・回収率24.0% | 同上 |
| 調査規模（第61回） | 2025年10〜11月・13,277人・回収率18.0% | [第61回学生生活実態調査](https://www.univcoop.or.jp/vision/vision_1896.html) |
| アルバイト収入の使途「サークル費用」 | 17.1%（コロナ前は27.2%） | [第60回](https://www.univcoop.or.jp/vision/vision_493.html) |

読み取れることは3つある。第一に、**1年生の8割はどこかのサークルに入る**ので、4月は明確に需要のピークである。第二に、第61回調査では参加率がコロナ禍前水準に回復した一方で「ひとりひとりのサークル活動の方法や内容、関わり方などが変化している可能性」が指摘されており、組織的な活動より個々の関係性への接続が重視される方向に緩やかに動いている。第三に、**サークルにかける金額は依然コロナ前より低い**（17.1% < 27.2%）。

なお、文部科学省の全国学生調査に関して「サークル活動せず56%」という報道があるが、これは**「授業期間中の1週間で部活動・サークル活動に充てる時間が0時間」と答えた学生の割合**であって「未所属率」ではない（[日本経済新聞](https://www.nikkei.com/article/DGXMZO60481280Y0A610C2CE0000/)、2021年度調査では69%に上昇と報じられている）。所属していても実質活動していない層が半数以上いる、と読むのが正確だ。

> **要するにこうすればよい**：ターゲットは「4月に入る気満々の1年生」と「所属はしているが実質動いていない層」の二段構え。そして**会費を限りなくゼロに近づけることが、そのまま競争力になる**。金額で他団体に負ける理由を最初から作らない。

## 2. 新歓カレンダー：4日間の勝負と1か月のロングテール

多くの大学で、新歓は「入学式直後の数日間の集中期」と「4月いっぱいのロングテール」の二層構造になっている。

| 大学 | 集中期の日程 | 時間 | 備考 |
| --- | --- | --- | --- |
| [早稲田大学（2026年度）](https://www.waseda.jp/inst/student/news/11714) | 4/1（水）〜4/4（土） | 10:00〜17:00 | ブース設置・ビラ配布・パフォーマンスステージ |
| [早稲田大学（2025年度）](https://www.waseda.jp/inst/student/news/9820) | 新歓期間は4/1〜4/30（予定） | ― | 4/2に8号館B1Fで合同説明会、3号館前屋外ステージ・7号館3F教室でパフォーマンス |
| [明治大学 和泉（2026年度）](https://www.meiji.ac.jp/campus/circle/2024shinkan.html) | 4/1（水）〜4/3（金）、4/6（月） | 9:30〜17:30 | ― |
| [明治大学 生田](https://www.meiji.ac.jp/campus/circle/2024shinkan.html) | 4/3（金）〜4/8（水）（4/5・4/7を除く） | 10:00〜15:00 | ― |
| [明治大学 中野](https://www.meiji.ac.jp/campus/circle/2024shinkan.html) | 4/1〜4/3、4/8 | 12:30〜15:30／4/8は12:30〜14:00 | キャンパスごとに枠が違う |
| [龍谷大学](https://www.ryukoku.ac.jp/nc/news/entry-18004.html) | ビラ配布 4/1・4/3〜4/6／ブース設置 4/3〜4/4 | ― | 深草・瀬田キャンパス。ブース5つ巡るスタンプラリーあり |

集中期の実働は**実質20〜30時間しかない**。一方で早稲田のように新歓期間そのものは1か月確保され、その間は作品展示・チラシ配架・個別公演が可能な運用もある。

逆算すると、立ち上げ1年目の準備はこうなる。

| 時期 | やること |
| --- | --- |
| 前年12月〜1月 | 団体設立申請（大学による。§3参照）、コンセプトと活動形式の確定 |
| 2月 | SNSアカウント開設、固定ポスト・プロフィール整備 |
| 3月上旬 | 週2〜3回の定期投稿を開始、ビラ入稿、オープンチャット/Discord開設 |
| 3月下旬 | 合格発表・入学手続き日に合わせた告知、体験会の日程確定・公開 |
| 4/1〜4/4 | ブース・ビラ・パフォーマンスの集中投下 |
| 4月中旬〜下旬 | 体験会を複数回、展示・個別公演などロングテール施策 |
| 5月 | 正式入会、定着フェーズへ移行 |

> **要するにこうすればよい**：**4月1日は準備の締切であって開始日ではない**。3月中にSNSと入会導線を稼働させ、4日間は「すでに知っている人に会いに来てもらう日」にする。集中期に初めて存在を知らせる設計は、認知から入会までを4日で完走させることになり無理がある。

## 3. 大学のルールを最初に読む

新歓は自由行動ではない。**ルール違反は活動停止に直結する**ので、企画より先に規程を読む。

### 3.1 新歓期の活動ルール

早稲田大学の例が具体的で参考になる。

- ビラは**「必ず手渡し」**。積み上げ方式の配布は禁止で、地面に落ちたビラは**その場で即回収**する義務がある（[2026年度注意事項](https://www.waseda.jp/inst/student/news/11714)）
- プラカードは**四隅を丸くする、カバーをかける**など、接触で怪我をさせない安全対策が必須（同上）
- 4月1日・2日は入学式の同時中継会場となる14号館・15号館への立ち入りが禁止（同上）
- **エリア規制が前提**。大隈記念講堂前、戸山キャンパス内、キャンパス周辺の商店街等でのチラシ配布は禁止（[2025年度概要](https://www.waseda.jp/inst/student/news/9820)）

立て看板は別枠の規程になっていることが多い。東京大学教養学部学生自治会の例では、ベニヤ板1枚（約182cm×約91cm）につき**54kgの重り**（18Lポリタンク満水3つ相当）、ポスタースタンドには36kgの重りが必須で、点字ブロック上・マンホール・建物出入口上への設置は禁止。裏面に団体名・重りの重量・緊急連絡先・撤去予定日を記入し、**2026年1月1日から設置前の広報局への届出が必須**になった（[東京大学教養学部学生自治会](https://todaijichikai.org/service/tatekan)）。

また、大学側は非公認団体を装った勧誘に警戒している。明治大学は「非公認サークルには、正体を隠した悪徳商法やカルト宗教などの勧誘が含まれる場合があります」「大学公認団体を装った学外団体、カルト団体、悪質商法、闇バイト（特殊詐欺）などのイベント告知や勧誘を行っている場合もあります」と明記している（[明治大学](https://www.meiji.ac.jp/campus/circle/2024shinkan.html)）。

### 3.2 団体設立のリードタイム

ここが立ち上げ時の最大の落とし穴で、**大学によっては数か月〜1年かかる**。

| 大学 | 設立要件・手続き | リードタイム |
| --- | --- | --- |
| [筑波大学](https://ssc.sec.tsukuba.ac.jp/office-of-student-welfare/activities-application-2) | 学生生活課へ「アンケート送付希望」をメール（件名形式指定あり）→新規団体向けアンケート | 設立は毎年4月・10月の年2回。**許可まで最短3か月**。4月設立は前年12月まで、10月設立は6月までに申込 |
| [明治学院大学](https://www.meijigakuin.ac.jp/faq/00115.html) | 未公認サークルの設立に**届出は不要**。公認を目指す場合は「設立準備団体」として申請 | 設立準備団体として**1年間活動**した後にあらためて公認申請。申請時期は毎年4月 |
| [信州大学](https://www.shinshu-u.ac.jp/campus_life/studentsupport/circle/lend.html) | 学生の構成員**5名以上＋規約**。専任教職員の顧問1名以上、代表・副代表・連絡員・会計担当が各1名以上 | 新規団体は随時申請可（継続団体は毎年5月に届出） |

規約には一般的に、団体名称・活動場所・活動目的・組織（役員）・顧問・議決の方法・会計の決まりを書く（信州大学の記載事項）。

> **要するにこうすればよい**：**自分の大学の学生課ページを最初に開き、「設立申請の締切」と「新歓活動の禁止事項」の2点だけ先に確定させる**。締切が前年12月なら、思い立った年の4月新歓には間に合わない。その場合は明治学院型の「未公認で先に活動を始め、実績を作ってから公認申請」という二段階ルートを取るのが現実的で、発起人5名＋規約1枚を最初のマイルストーンに置けばよい。

## 4. 「入りやすさ」の設計：語学系サークルの実例

多言語・英語系サークルの最大の障壁は「英語を話すのが恥ずかしい」である。実在団体はこれを**運営設計**で処理している。

| 団体 | 規模・形式 | ハードルを下げる仕掛け |
| --- | --- | --- |
| [東京大学語学愛好会](https://ut-base.info/circles/222) | Discord約170人・アクティブ20〜30名 | 年会費無料、選考なし、通年募集、ゼミは週1・全体定例会は1〜2か月に1回、全員参加必須の活動なし。**「離脱する人はあまりいない」** |
| [日本女子大学 E.S.S.](https://www.jwu.ac.jp/unv/seg_student/circle/ess.html) | 平日週2回・12:40〜13:10（昼休み30分） | 年間費用**原則なし**、他サークルとの掛け持ち可、初心者・未経験者歓迎 |
| [東京大学 E.S.S.](https://ut-ess.com/) | Drama／Speech／Discussion の3セクション | Speechは「スピーチ未経験でも心配無用。2年生が始めから優しく丁寧に教えます」、Discussionは「英語が苦手でも大丈夫！」「メンバーも勉強中なので一緒に練習しましょう」 |
| [南山大学 E.S.S.](https://office.nanzan-u.ac.jp/student-services/clubs/clublist/bunkakei-kokusai/000145.html) | 部員103名。ディベート部門とガイド部門 | 「ルールや用語の説明は部員が丁寧にしますので初心者の方でもご安心ください」「今の英語力に自信が無い方も大歓迎」 |
| [青山学院大学 E.S.S.](https://agu-ess.com/) | Daily活動とSection活動の二層構造 | Dailyは「ESS活動を体験する期間」、Sectionは「活動を通して英語を学ぶ期間」。4月に新歓説明会・ウェルカムキャンプ、5〜7月にセクション体験 |

東京大学語学愛好会は多言語サークルの参照モデルとして特に有用だ。学部1年から博士課程の院生まで在籍し、執行代を固定せず「やりたい人が自主的に担当」する運営で、ゼミ（特殊相対論原論文＝ドイツ語、日葡辞書・日本大文典、伝奇集＝スペイン語、印欧祖語、古典ギリシャ語、韓国語小説購読など）単位で動いている。

制度面の後押しもある。明治大学は公認サークルに対して「**4月中は体験入部（仮入部）期間とし、正式な入部を5月以降にするとともに、入会金・年会費等の徴収については正式な入部後にする**」よう依頼している（[明治大学](https://www.meiji.ac.jp/campus/circle/2024shinkan.html)）。

> **要するにこうすればよい**：**「無料・選考なし・全員参加必須の活動なし・掛け持ち可」の4点セットを規約レベルで明文化し、それをそのまま広報コピーにする**。加えて、募集文には「経験不問」ではなく**「上級生も未経験から始めた」という具体的事実**を書く。抽象的な歓迎表明より、東大E.S.S.や南山大E.S.S.のような一文のほうが効く。会費徴収は5月以降に回し、4月は完全に無料の体験期間にする。

### 5.2 入会導線をどこまで短くするか

東京大学語学愛好会の入会方法は「**Xやインスタグラムで入会希望のDMを送ってDiscordに入る**」だけで、フォーム記入という摩擦がない。それでいて「離脱する人はあまりいない」（[UT-BASE](https://ut-base.info/circles/222)）。**フォームは必須ではない**。

- [慶應義塾「Circle Square」](https://orientation.keio-zenkyo.net/)：全塾協議会に設置された新歓実行委員会が運営する「唯一の慶應義塾大学公認のサークル紹介サイト」。団体紹介動画をYouTubeで公開し、掲載情報は2026年1月に収集された
- [明治大学 2026春新歓HP](https://www.meijiunvshinkan.com/)：約250の公認サークルが参加し、約240団体がブース出展。ブース／PA／ミニPA／体験ブース／展示／大型展示／スタンプラリー／インタビュー／インスタ／履修相談／ポスター／封筒／アルバム／ビラ の**14企画**がパッケージ化されている。公式SNSは Instagram @shinkaninsta、X @meijinew

## 6. 定着（リテンション）：辞めさせない設計

### 6.1 離脱の最大要因は「なあなあ運営」

北海道大学で1人からサークルを立ち上げた運営者の記録によれば、人数は1年目（新歓時期を逃した）→2年目10人入部→3年目21名（新入部員8名込み）と推移した。広報は「投稿は定期的かつ多め」「コンセプトがわかるような内容」「SNSの特性も考慮」に加え、ビラ配りと構内でのゲリラ的パフォーマンス。そして離脱の原因は**「毎回の活動でやることが明確でない」こと**と分析され、対策として「目指すイベントを明確にする」「各回の活動内容を前もって明確に決めておく」を実施した。運営情報はNotionで一元管理している（[note・個人記事](https://note.com/tam_irish/n/nbcdf8ee3b12e)、一次情報ではないため参考扱い）。

多言語サークルに翻訳すれば、**「今週のテーマ・使う言語・進行形式を事前に告知する」ことがそのまま定着施策になる**。

### 6.2 オンボーディングの型

コミュニティ運営の実務では、①適切な量の情報を1週間〜1か月かけて小出しにする ②自己紹介で参加目的を把握し居場所感を作る ③グッズ配布で所属意識を作る ④カルチャー・ビジョンをしつこいくらい何度も伝え、ルールは最小限にする ⑤マニュアルと質問窓口を用意する ⑥8人以下の少人数座談会 ⑦1対1面談 ⑧バディ／メンターでメンバー同士を接続する、という8パターンが整理されている（[Commune](https://commune.co.jp/magazine/ob-8pattern/)、事業会社メディアのため参考扱い）。

### 6.3 「4月に取り逃した層」を秋と通年で拾う

| 秋新歓 | [筑波大学「Tsuku・Koi 2025」](https://www.tsukuba.ac.jp/news/20251002104838.html) | 2025年10月2日、秋季入学式後に大学会館講堂前ホワイエ等で開催。延べ約300名が来場、22の学生団体が活動紹介、5団体がパフォーマンス。秋入学の留学生の要望を受け2022年に開始 |
| 通年募集 | [UT-BASE 秋の合同新歓](https://ut-base.info/articles/171) | UmeeT：秋学期加入者が40%／東京大学新聞社：20%／TEDxUTokyo：4〜5月開催までに半分程度の見込み。3団体とも応募期間は「通年募集」 |
| 通年募集 | [東京大学語学愛好会](https://ut-base.info/circles/222) | 年間を通して募集、選考なし |

**新規加入の2〜5割を秋が占める団体が実在する**以上、募集を4月で閉じるのは機会損失にほかならない。

> **要するにこうすればよい**：**①活動を毎回「事前に決まった内容」として告知する ②募集を通年で開けたままにする ③新入部員の最初の1か月に、自己紹介・少人数座談会・既存メンバーとの1対1接続を意図的に入れる**。この3点で、新歓に投じたコストの取りこぼしが最も減る。休会を正式に申告できる仕組みを置くと「今は行けない」と言いやすくなり、正確な人数把握と復帰しやすさが両立するとされるが、これは一次情報が確認できていないため要検証（§7参照）。

## 7. 立ち上げ1年目の実行チェックリスト

| フェーズ | タスク | 判断基準 |
| --- | --- | --- |
| 制度 | 自大学の設立要件と申請締切を確認 | 締切に間に合わなければ未公認でスタート（明治学院型） |
| 制度 | 発起人5名＋規約1枚を用意 | 信州大学型の最低要件を目安にする |
| 制度 | 新歓期の禁止事項（配布方法・エリア・立て看板）を読む | 学生課ページを印刷して手元に置く |
| 設計 | 会費ゼロ・選考なし・掛け持ち可・全員参加必須なしを明文化 | 規約と募集文の両方に書く |
| 設計 | 「今週のテーマ・使う言語・進行形式」を毎回事前告知する運用に | 告知テンプレを作る |
| 広報 | X＋Instagramを2月に開設、3月から週複数回投稿 | Instagramはストーリーズ主軸 |
| 広報 | LINEオープンチャットまたはDiscordを開設、QRをビラに載せる | ビラには団体名・活動内容・連絡先を必ず記載 |
| 広報 | 大学公式のサークル紹介サイト／新歓実行委員会企画に応募 | 募集告知を見逃さない |
| 実施 | 4/1〜4/4に集中投下、4月中に体験会を複数回 | 説明会ではなく実体験の場にする |
| 定着 | 4月は無料の体験期間、正式入会と会費徴収は5月以降 | 明治大学が公認サークルに依頼している運用 |
| 定着 | 募集を通年で開けたままにし、秋にも告知を打つ | 秋加入が2〜5割を占める団体が実在する |

> **要するにこうすればよい**：**制度→設計→広報→実施→定着の順に固める**。逆順（先にSNSを作ってから中身を考える）だと、集中期に「で、何をするサークルなの？」に答えられず離脱を招く。

## 8. 裏取りできなかった／要確認の項目

以下は今回の調査で一次情報にたどり着けなかったもの。**断定せず、自分で確認してから使うこと**。

- **新入生がサークルをどこで知ったか**（SNS／ビラ／冊子／友人 の内訳）を示す定量調査は、日本語・英語とも発見できなかった。実務記事では「SNSが最重要」とされるが数値の裏づけがない（**要確認**）
- **語学系サークル／E.S.S. に限定した幽霊部員率・年次定着率・退部理由の定量データ**は発見できなかった。全国大学生協連の調査は所属率までで、団体内定着率は扱っていない（**要確認**）
- **休会制度・不参加の正式申告の仕組み**が定着率を上げるという説は、一次情報を確認できていない（**要確認**）
- **LINEオープンチャットを新歓に使った実際の大学サークルの参加人数・転換率**の事例は、LINE公式ブログを含め確認できなかった。確認できたのはキャンペーンの「10人以上」要件のみ（**要確認**）
- **Discordを新歓の主導線に据えている大学公認サークルの一次事例**は、東京大学語学愛好会（UT-BASE掲載）以外に確認できていない。同ページもUT-BASE編集部による二次的な掲載情報である（**要確認**）
- **秋新歓の全国的な実施率や春に比べた規模感を示す統計**は見つからなかった（筑波大学とUT-BASE記事の個別事例のみ）（**要確認**）
- **南山大学 E.S.S. のセクション構成**は、閲覧時点の大学公式ページではディベート・ガイドの2部門と記載されており、以前の資料にある「5セクション（Debate／Discussion／Drama／Guide／Speech）」とは一致しない。現状は大学ページの記載を採用した（**要確認**）
- **早稲田大学の新歓ブースの区画数・抽選方式・申請期限・使用料**など具体数値は、募集要項PDFがHTTP 403で取得できず未確認（**要確認**）
- **文部科学省の全国学生調査**は、2019年度「0時間56%」「2021年度69%」まで報道ベースで確認したが、最新（令和6年度・第4回試行実施）のPDFはテキスト抽出できず、最新値は未確認（**要確認**）
- 「**#春から〇〇**」ハッシュタグを名指しした偽装勧誘の注意喚起は、明治大学の現行ページ本文では確認できなかった。確認できたのは「非公認サークルには正体を隠した悪徳商法やカルト宗教などの勧誘が含まれる場合がある」「大学公認団体を装った学外団体、カルト団体、悪質商法、闇バイト（特殊詐欺）などのイベント告知や勧誘」という記載（**要確認**）
- 立て看板の規程は大学ごとに大きく異なる。本文で示したのは東京大学教養学部学生自治会の基準であり、**他大学にそのまま当てはまらない**
