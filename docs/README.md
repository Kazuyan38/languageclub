## この資料の読み方

- **公認要件・規約・会計・保険の「正典」は [04](./04-founding-and-operations.md)** です。他のドキュメントにも要約が出てきますが、条文レベルの比較は 04 に集約しています。制度が改定されたら 04 を直してください。
- 各ドキュメントは末尾に「**要確認**」節を持ちます。裏取りできなかった数値、HTTP 403/404 で本文を取得できなかったページ、公式サイト間で記述が食い違う項目をそこに分離してあります。断定調の本文と、確度の低い情報を混ぜないための構成です。
- 人数要件は調査範囲でも **5名〜21名と7倍の開き**がありました。「一般にこうだ」と読める記述でも、必ず自分の大学の学生課で確認してください。
- 大会の日程・締切は調査時点の回のものです。年間サイクルの目安として使い、応募前に主催者の最新情報を見てください。

## この資料に無いもの

サークル名、扱う言語、活動日時、会費、連絡先といった**この団体固有の情報**は入っていません。それらは [07](./07-startup-checklist.md) の「最初に決めるべき7つの問い」で決めたうえで、リポジトリ直下の [README](../README.md) に書いてください。
