# サークルの立ち上げ・公認化・運営の実務

これから大学でサークルを立ち上げる人が、「何人集めればいいのか」「いつ何を出すのか」「公認になると何が変わるのか」「お金と規約と引き継ぎをどう回すのか」を、実際の大学規程の条文レベルで把握するためのドキュメントです。早稲田・明治・神奈川・東京外国語・岡山・信州・高知工科・山形・筑波・一橋の公開規程を一次資料として突き合わせ、共通する型と、大学ごとに7倍の開きがある要件の差を整理しました。

なお本書に出てくる数値・書類名はすべて「その大学の」ルールです。あなたの大学の要件は必ず学生課／課外活動センターで確認してください。人数要件だけでも3名から21名まで幅があります。

---

## 1. 全体像：非公認から公認までは「段階制」が標準

調べた大学すべてで、いきなり公認団体にはなれません。一定期間の活動実績を積んでから昇格する二段階〜三段階の制度になっています。つまり**立ち上げ初日から「公認申請の証拠を貯める活動」を始める必要がある**というのが最重要の示唆です。

## 2. 公認になると何が変わるか

公認化は名誉ではなく実利の問題です。特に**保険**が決定的です。

| 項目 | 公認団体 | 登録／同好会 | 無届 |
|---|---|---|---|
| 部室（サークルボックス） | ○（早稲田は公認でも全団体には割当なし） | 高知工科は△、信州の登録団体は○ | × |
| 教室・共通施設の使用 | ○ | 早稲田の登録サークルは教室貸出可 | 原則不可 |
| 補助金・助成金の申請 | ○ | 高知工科の同好会は特別助成のみ | × |
| 新歓ブース／構内出店 | ○（優先割当） | 早稲田の登録サークルはラウンジ使用のみ | × |
| 学生教育研究災害傷害保険（学研災） | ○ | 大学の認定次第 | × |
| 大学メールアカウント・HP掲載 | ○ | 高知工科の同好会はメールアカウント× | × |

学研災の補償対象となる「課外活動中」は、[日本国際教育支援協会](https://www.jees.or.jp/gakkensai/index.htm)の定義で**「学校の規則にのっとった所定の手続きにより学校の認めた学内学生団体・サークルの管理下で行う文化・体育活動」**とされています。学校が禁じた時間・場所での活動や、学校が禁じた行為の最中は補償されません。[明治大学取扱要領](https://www.meiji.ac.jp/campus/circle/6t5h7p00000g8e3l-att/a1744695632734.pdf)第13条も、公認サークルへの便宜供与の1つとして明示的に学研災の適用を挙げています。

**要するにこうすればよい**：「非公認でゆるくやる」は、事故が起きた瞬間に無保険になるという意味です。合宿・遠征・イベントなど怪我のリスクが上がる活動をやる前に、最低でも大学への「届出／登録」だけは済ませておくこと。届出は公認より要件が緩く、早稲田も「公認予定のないサークルでも登録申請を推奨」しています。

## 4. 規約（会則）の作り方

規約はどの大学でも必須書類です。[一橋大学が公開している規約例](https://www.hit-u.ac.jp/shien/campuslife/pdf/sample_kiyaku.pdf)（PDF原文を確認）は全12条＋付則の構成で、そのまま骨子に使えます。

| 条 | 見出し | 内容 |
|---|---|---|
| 第1条 | 名称 | 本部（サークル）は○○○○部（サークル）と称する |
| 第2条 | 場所 | 目的に賛同し自発的に参加する者で組織し、本部を一橋大学に置く |
| 第3・4条 | 趣旨・目的 | 活動を通じて部員相互の親睦、及び教養・健康の推進を図り、技術の向上に資する |
| 第5条 | 活動 | ①通常練習 ②定期戦への参加 ③その他適当と認める大会等への参加 ④昨年度までの活動実績（月別に列挙） |
| 第6条 | 組織 | 代表1名／副代表若干名／総務・主務担当若干名／会計担当若干名／如水会（OB）担当若干名。また顧問を置き、教員の立場から助言と指導を与える |
| 第7条 | 除名 | 活動目的に反する行為を行った場合は除名、または期間を定めて活動参加を制限 |
| 第8条 | 議決 | 「部会」を置き、企画運営に関する事項を審議・決定する |
| 第9条 | 会計 | 運営経費は原則として部費及び趣旨に賛同する個人・団体からの援助金等を充てる |
| 第10条 | 事故防止の義務 | 事故を未然に防ぐ能力を取得し、常に最善の努力をする。不測の事態では人命救助を最優先 |
| 第11条 | 飲酒 | 「一橋大学学生の飲酒に関する基本原則」を遵守し、未成年飲酒をさせてはならない（**必ず規約に入れること**と明記） |
| 第12条 | その他 | 規約の改廃は部会により承認を受けなければならない |
| 付則 | — | 施行日 |

一橋大学の規約例は冒頭に「規約内または別紙に昨年度までの活動実績を記載してください。第11条の内容は必ず規約に入れてください。」という指示が太字で書かれています。なお、引用元となる「一橋大学学生の飲酒に関する基本原則」の本文は今回取得できませんでした（学生生活の手引き2025に収録されていることまでは確認、**要確認**）。

信州大学は会則に**団体名称・活動場所・活動目的・組織・役員・顧問・議決方法・会計・入退会手続き・部費・改正手続き**を記載するよう求めています。一橋の12条に「入退会手続き」「部費の額と徴収方法」を足すと、多くの大学の要求を満たせます。

**要するにこうすればよい**：一橋の12条をコピーして、①団体名と大学名を差し替え、②第5条の活動内容を自分のサークルの実態に書き換え、③自分の大学の飲酒ルールの正式名称に第11条を差し替え、④入退会と部費の条を足す。これで初稿は1時間で完成します。ゼロから書かないこと。

## 5. 役員体制と顧問

役員の人数と学年構成は、多くの大学で「制度として世代交代を強制する」設計になっています。

| 大学 | 必須の役職 | 学年・兼任の縛り |
|---|---|---|
| 早稲田 | 会長・幹事長・副幹事長・会計を各1名 | 三役のうち1名以上は必ず3年生以下（大学院生不可）。同一サークル内・他サークル三役との兼任不可 |
| 明治 | 幹事長及び会計（本学学生） | 同一団体内又は複数団体の役員兼務は全面禁止（第5条） |
| 信州 | 代表1名、副代表・連絡員・会計担当を各1名以上 | 会計に責任が持てる体制の整備 |
| 岡山 | 責任代表者3名以上（同好会）／5名以上（準加入） | 準加入の責任代表者5名は他サークルとの兼任不可、幽霊部員は認めない |
| 同志社 | 会長・副会長・会計の三役（要確認） | 三役は学部生に限る（要確認） |

役職の職務内容そのものについては、大学公式の定義は薄く、代表・副代表・会計・書記・広報・渉外という分け方は[学生向けメディアの記事](https://www.gakuseikyosan.com/media/?p=1996)などで一般的に説明されているにとどまります（一次情報ではない、**要確認**）。

顧問については神奈川大学の[顧問・部長等に関する要綱](https://www.kanagawa-u.ac.jp/campuslife/activities/file/circle_05.pdf)が最も具体的で、第4条で「部が推薦する専任教職員を学生生活支援部長が委嘱し、就任にあたって**就任承諾書**を提出する」、第5条で「任期は2年、再任は妨げない。任期満了又は辞任で退任する場合も、あらたに後任者が委嘱されるまでは在任する」、第7条で「顧問・部長・副部長並びに監督・コーチ等にかかる**手当は支給しない**」と定めています。

**要するにこうすればよい**：顧問依頼は「就任承諾書に判子をください」という具体的な依頼として持っていく。無報酬であることを前提に、負担が軽い（年数回の書類署名と、事故時の連絡先）ことを最初に伝えるのが誠実です。役員は、規約上「会計だけは必ず代表と別人」にしておくと、後述の会計トラブルの大半を防げます。

## 6. お金の実務：会費・会計・補助金

会計の一次資料として最も実務的なのが[高知工科大学の学生団体会計マニュアル](https://www.kochi-tech.ac.jp/kyomu/club/manual.pdf)（PDF原文を確認）です。要点は次のとおり。

- **会計担当は2名置く**：「一人ですべての会計をやることは大変ですので、可能であれば2名会計担当を決めましょう」
- **団体名義の口座を必ず開設する**：「高知工科大学　○○○部または同好会（←団体名）」という名前の口座を開設。「部費は必ず一度口座に入れましょう。個人の手元で管理するのはトラブルのもとですので、やめましょう」
- **会計年度は4月始まり翌年3月締め**。年度末に事務局・学生支援課によるヒアリング（面談）があり、会計書類の提出を求められる
- **通帳に鉛筆でメモ**：記帳したら預金明細の横に、直接振込か現金払いかも含めて簡単なメモをつける
- **領収書の3要件**：①宛名を団体名で書いてもらう ②但し書きは具体的に記入してもらう ③必ずハンコをもらう。高額物品購入時は見積書・納品書の発行も依頼。コンビニのコピーや電車代など小額でも必ずもらう。領収書がない場合は請求書やレシート等、内訳がわかるものを併せて入手し、紛失時は直ちに再発行を依頼する
- **立替払い**：「領収書等貼付用紙（支出）作成の際、会計担当は、立替人に**署名・押印・償還日**の記入をしてもらってください。※トラブルを防ぐために必ず行ってください」
- **年間会計報告書（収支簿・決算書・予算書）**は代表と会計の双方で確認し、確認印を押印する
- **ペナルティ**：「会計処理に不備がある『部』については、後援会からの助成金の減額あるいは助成取り消しもありえます」

早稲田大学も同様に、公認申請に添付する領収証について「必ずサークル名を宛名とし、但し書きなどで使途内容が明記されており、かつ**発行者の住所・電話番号・捺印**があること」を要求しています。

### 補助金の例

| 項目 | [早稲田大学 課外活動補助金](https://www.waseda.jp/inst/student/circle/procedures/subsidiary) |
|---|---|
| コース | 30万円コース／15万円コース／10万円コース |
| 給付率 | 決定したコース金額を上限に、イベント実施報告書で直接経費と認められた経費の**半額** |
| 直接経費の定義 | サークル設立の趣旨に沿った支出であり、イベントと関連が明確、かつ個人でなくサークルに帰属するもの |
| 対象外 | 食費、宿泊費、交通費、衣装代（ユニフォーム含む）、小道具代、贈答品、レセプション費用 |
| 給付時期 | 実施報告書の提出から2か月後が目安 |

なお、[高知工科大学](https://www.kochi-tech.ac.jp/student/activities/organization.html)では一般助成金（「部」のみ、学生団体活動費は5月15日期限）と特別助成金（公認団体すべて、物品費助成1月29日期限、旅費助成は大会1週間前・終了後2週間以内）に分かれています。

会費の相場については、大学公式や公的統計による一次データを見つけられませんでした。参考として[広島修道大学E.S.S.](https://www.shudo-u.ac.jp/lifesupport/club/ess.html)は入部費なし・部費1,500円／年で運営しています。学生向けメディアでは「月1,000円前後から数万円まで」という幅の記述がありますが、具体的な金額例の裏付けは取れませんでした（**要確認**）。

**要するにこうすればよい**：立ち上げ月に、①団体名義口座の開設 ②会計担当2名の選任 ③領収書貼付台紙と収支簿のスプレッドシート作成、の3つを済ませる。補助金は「半額給付・飲食は対象外」が典型なので、交流会の飲食費は最初から自己負担で予算を組み、補助金は講師謝礼・教材・機材など「サークルに帰属するもの」に充てる設計にすると通りやすくなります。

## 7. 施設・場所の確保

部室は「公認になれば自動的にもらえる」ものではありません。[早稲田大学の部室（単独部室・曜日指定部室）](https://www.waseda.jp/inst/student/circle/registration)は、公認サークルであることが前提のうえで、「部室の利用資格は当該年度限りとなっており、継続して使用する場合は、毎年度大学が定める条件を満たすことや所定の手続きを期間内に行う必要があります」とされ、曜日指定部室の使用可能日数は公認申請の連続回数に応じて週1日／週2日／週3日と段階化されています。継続には前年度に「合宿・遠征届」「活動報告書」「イベント実施報告書」のいずれかを1回以上提出していることが条件です。

神奈川大学は毎年5月末の報告義務書類の1つに「部室利用許可願」を挙げており（第6条(7)）、明治大学の年度継続手続にも条件付き書類として「サークルボックス・キャビネット使用申請書」があります。

活動時間・日程にも制約があります。[東京外国語大学](https://www.tufs.ac.jp/student/extraordinary/rule.html)は課外活動禁止日（夏季一斉休業、外語祭、年末年始、共通テスト、前期・後期日程試験の期間など）を設け、学外活動は「原則午前8時から午後8時まで」とし、超過時は顧問教員の連絡先記入を必須としています。学研災も「学校が禁じた時間もしくは場所での活動」は補償対象外なので、この制限は保険と直結します。

**要するにこうすればよい**：部室は当てにせず、まず「教室を毎週予約する」運用で始める。教室予約は登録段階でも可能な大学が多く（早稲田の登録サークルは教室貸出可）、部室は活動実績の報告書を毎年出し続けた先にあるご褒美だと考える。カフェやオンライン（Zoom／Discord）を主な活動場所にする場合、それが課外活動として認められるか、学研災の適用範囲に入るかについての一次情報は見つかりませんでした（**要確認**、必ず学生課に確認してください）。

## 8. コンプライアンスと処分リスク

規程は「取消されうる」側から読むと本質が見えます。

| 大学 | 処分事由 | 処分内容 |
|---|---|---|
| [明治大学](https://www.meiji.ac.jp/campus/circle/6t5h7p00000g8e3l-att/a1744695632734.pdf)（第14条） | ①不法行為 ②不祥事 ③第2条第2項の団体（営利・宗教・反社会的・学外団体の支部等）と認めた場合 ④提出書類に虚偽の記載 ⑤継続手続その他必要な手続を期間内に行わなかった ⑥継続が承認されなかった ⑦必須の説明会・講習会に正当な理由なく欠席 ⑧その他 | 公認の取消し等（処分は併科あり） |
| [神奈川大学](https://www.kanagawa-u.ac.jp/campuslife/activities/file/circle_05.pdf)（第7〜9条） | 報告義務を怠った／要件を満たさない／大学の名誉を著しく傷つけた／団体からの申出／その他 | 認可の取消（第7条）、活動停止の仮処分（第8条）、学内施設の利用禁止（第9条） |

明治大学は登録を認めない団体として「営利活動」「宗教的活動」「反社会的な活動」「学外団体の支部として活動」「その他不適格と判断した団体」の5類型を挙げています。**学外の語学サービスや企業と提携する形の運営は、この「営利活動」「学外団体の支部」に抵触しうる**ので、スポンサーや提携を検討する場合は事前に学生課へ相談してください。

また明治大学第9条第5項は、役員に対し「部長に対し定期的に活動報告を行い、またサークル内でのトラブルや事件・事故等について**直ちに**部長に報告しなければならない」と義務づけています。同第4項は、注意喚起説明会や幹部員講習会に役員1名を必ず参加させることを求めています。

大学名の使用にも承認が要る場合があります。[長崎大学の課外活動規程](https://www1.g-reiki.net/nagasaki-u/reiki_honbun/x893RG00000900.html)第10条第4項は「一般学生等は、集会等の行事（学外にあっては、本学の名称を用いる場合に限る。）を行おうとするときは、行事の3日前までに別に定める届出書を学生支援課に提出し、副学長による承認を受けなければならない」と定めています。

SNS運用については、[産業能率大学の学生向けソーシャルメディア利用ガイドライン](https://www.sanno.ac.jp/students/snsguide.html)が①自宅住所や個人の電話番号・メールアドレスは絶対に書き込まない ②他人が写り込んだ写真の無断投稿は肖像権・プライバシー権の侵害 ③顔写真の使用やコンテンツのコピー&ペーストは著作権侵害 ④連携先から知り得た情報を漏らさない ⑤個人への集中攻撃は名誉毀損や人権侵害につながる、の5点を挙げています。あわせて「投稿前に再確認する」「削除しても情報は残る」「匿名でも特定されうる」と注意しています。

なお、サークルが名簿・連絡先を管理する際の保管期間・同意取得・第三者提供に関する大学公式の指針や、学生団体向けに特化したハラスメント防止ガイドラインの全文は、今回取得できませんでした（**要確認**）。

**要するにこうすればよい**：規約に「除名条項」「事故防止義務」「飲酒条項」を入れたうえで、運用として(a)広報アカウントは個人アカウントと分け、投稿前に必ず2人目がチェックする、(b)集合写真の掲載は撮影時に口頭で可否を確認し、NGの人を記録する、(c)名簿は共有ドライブの限定公開フォルダに置き、閲覧権限を役員のみにする。これだけで大半の炎上と個人情報事故は防げます。

## 9. 引き継ぎ・世代交代

高知工科大学の会計マニュアルは「よくあるトラブル」として**口座の代表者名義変更（毎年）**を筆頭に挙げ、「通帳の代表者名義は、代表が変わる度に必ず新しい代表に変更しましょう。そのままにしておくと名義人が卒業→音信不通となることがあります」と警告しています。

制度側でも世代交代は強制されます。早稲田大学は三役のうち1名以上を必ず3年生以下とし、明治大学は本承認の要件として「部員の構成が1年次から4年次までのうち3学年以上」を課しています。岡山大学の準加入は責任代表者を「入学から4年以内の学生」に限定し、幽霊部員を認めていません。手続としては明治大学の「学生団体役員交代届」「部長交代届」「団体解散届」、筑波大学の「学生団体設立願記載事項等変更届」などがあり、いずれも役職者が変わったら都度提出が必要です。

**要するにこうすればよい**：代表交代の作業を「引き継ぎ会」ではなく**チェックリスト**にすること。最低限、①銀行口座の名義変更 ②大学への役員交代届の提出 ③SNS・メール・共有ドライブの管理者権限の移譲 ④規約と会計書類の所在の共有 ⑤顧問への新代表の紹介、の5項目です。特に①と③は「卒業して連絡が取れない」が発生した瞬間に復旧が極めて困難になるので、卒業式前に必ず終わらせてください。

## 10. 語学・多言語サークル固有の設計ポイント

学部横断の要件（早稲田の「2学部以上」、神奈川の「複数の学科又は学年」、東京外大の「複数学部又は複数の言語・地域」）は、語学系サークルにとってはむしろ有利です。もともと学部を問わず人が集まるためです。特に東京外国語大学は要件そのものに「複数の言語・地域にわたっていること」を含んでおり、多言語サークルと制度の相性が良い例と言えます。

運営形態については、実在する大学公式の言語交換プログラムの設計が参考になります。

| 項目 | [東京大学 言語交換プログラム](https://www.u-tokyo.ac.jp/adm/inbound/ja/life-interact-ac-le.html) | [明治大学 言語交換プログラム](https://www.meiji.ac.jp/qfki0t000004xzci.html) |
|---|---|---|
| 運営 | グローバル教育センター留学生支援室 | 大学（学部生・大学院生・交換留学生対象） |
| マッチング方式 | オンライン掲示板でプロフィールを閲覧しメールで申請 | 「学びたい言語」「教えられる言語」をオンライン登録し、大学がパートナーを通知 |
| 形式 | 1対1 | 1対1または1対2 |
| 頻度の目安 | 規定なし（マッチング後は自主的に交流） | 週1回あたり60分を目安。「必ずしも毎週でなくてもかまわない」 |
| 言語の配分 | 規定なし | 共通言語（日本語または英語）と交換言語を**半々**の時間で使用 |
| 更新 | 学期ごとの再登録制 | 登録期間を設定（例：9月下旬登録、10月上旬にパートナー通知） |
| 注意書き | — | 「パートナーは語学の先生ではなく本学の留学生であり、異文化交流に重点を置くべき」 |

活動形式については、[東京大学E.S.S.](https://ut-ess.com/)がドラマ・スピーチ・ディスカッションの3セクション制を採り、スピーチは週2回の練習会、ディスカッションは週1回とセクションごとに頻度を変えています。対照的に広島修道大学E.S.S.は入部費なし・部費1,500円／年、週1回不定期16:30〜18:00という低負荷モデルです。

**要するにこうすればよい**：立ち上げ期は「全員が同じ活動に毎週出る」設計にしないこと。言語別または活動形式別のセクションを2〜3つ置き、参加負荷を選べるようにすると、公認要件（20名・複数学年）を満たす頭数を確保しながら離脱を防げます。ペアマッチングを導入するなら、明治大学の「週1回60分・言語は半々・毎週でなくてよい・相手は教師ではない」という4つのルールをそのまま自分たちのガイドラインに転記するのが最も安全です。

## 11. 最初の30日でやること

| 週 | やること | 理由 |
|---|---|---|
| 第1週 | 学生課で「設立締切・最短公認年数・人数要件・必要書類」をヒアリング。サークル名を確定 | 締切を外すと1年待ち。名称は後から変えられない |
| 第2週 | 顧問候補の教員に依頼（就任承諾書の様式を持参） | 兼務上限があるため早い者勝ち |
| 第3週 | 一橋の規約例をベースに規約を作成。役員（代表・副代表・会計2名）を決定 | 規約は全大学で必須書類 |
| 第4週 | 団体名義の銀行口座を開設。収支簿と領収書貼付台紙を用意。活動記録テンプレを作成 | 初回の支出から証憑が揃っていないと公認申請でやり直しがきかない |
