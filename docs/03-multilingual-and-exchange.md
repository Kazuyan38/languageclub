# 多言語・国際交流系サークルの実例と運営

これから多言語・国際交流系のサークルを立ち上げる人に向けて、国内外の大学が実際に公開している運営設計を集めて整理した資料です。
「何言語まで扱えるのか」「ネイティブはどこから連れてくるのか」「週何回・1回何分にするのか」「公認団体になるには何人必要か」といった、立ち上げ時に最初に詰まる論点を、実在する団体・制度の数値とともに扱います。
記載した情報は本文中のリンク先を実際に確認したうえで書いていますが、確認できなかったものは「(要確認)」と明記しています。

---

## 1. まず全体像：この領域には4つの型がある

公開情報を横断すると、多言語・国際交流系の活動は次の4つの型に整理できます。自分のサークルがどれを主軸にするかを最初に決めると、あとの設計がほぼ自動的に決まります。

| 型 | 中身 | 必要なもの | 代表例 |
|---|---|---|---|
| A. 分科会型（ゼミ／セクション制） | 参加者が言語や活動形式ごとの小グループに分かれる | 立ち上げの自由度、緩い所属ルール | 東京大学語学愛好会、東京外国語大学ESS |
| B. 多言語テーブル型（ランゲージカフェ） | 決まった曜日・場所に「言語ごとの机」を並べ、出入り自由で会話する | 固定の場所と時間、各言語の話者スタッフ | 筑波大学 Chat Events、名古屋学院大学 i-Lounge |
| C. 言語交換型（ペアマッチング） | 学習したい言語の話者と1対1で組み、互いに教え合う | マッチングの仕組み、時間配分のルール | 明治大学・東京大学・法政大学の言語交換プログラム |
| D. 国際交流イベント型 | 留学生と日本人学生をイベント・旅行・生活支援でつなぐ | 大学の国際センターとの連携、イベント企画力 | 早稲田大学WIC、上智大学GL-Net、立教大学の国際交流ボランティア |

**要するにこうすればよい**：ゼロから始めるなら、いきなり全部をやろうとせず「B（多言語テーブル）を週1回」だけで始めるのが最も低コストです。場所と時間を固定するだけで成立し、人が増えたらAの分科会に分岐させ、深く学びたい人にCの言語交換を紹介し、Dは学期の頭と学祭に年数回だけ差し込む、という順序が現実的です。

## 2. 分科会型：言語ごとの人数偏りを設計で吸収する

### 2-1. 東京大学語学愛好会 ── 「ゼミ」を誰でも立ち上げられる

多言語サークルの最有力モデルです。[UT-BASEの掲載情報](https://ut-base.info/circles/222)によると、活動は「ゼミ」単位で行われ、参加者が自分の興味あるテーマでゼミを立ち上げ、参加者どうしが自主的に勉強を進めます。テーマ・形式・頻度はすべて自由に決められます。

| 項目 | 内容 |
|---|---|
| 扱う言語の例 | ドイツ語、ポルトガル語、スペイン語、古典ギリシャ語、韓国語、アイヌ語など（言語に関わるものならテーマ自由） |
| ゼミの頻度 | 基本的に週1回 |
| 全体の定例会 | 1〜2か月に1回（対面が基本。2026年8月閲覧時点のUT-BASE記載。以前は「月1回」との記載） |
| 規模 | Discord登録 約170人／アクティブメンバー 20〜30名 |
| 選考・会費 | 選考なし・年会費無料 |
| 入会方法 | 既存会員からDiscordの招待コードをもらう。知り合いがいなければSNSのDMでコードを受け取れる |
| 参加資格 | 東京大学の学生でなくても誰でも加入可 |

[公式サイト](https://ut-gogaku.org/)には「義務的な活動はなく、有志の人々がゆるーく集まって、勉強したり何か作品を作ったりしてわいわいやっているところ」「会費や活動義務などは特に何もない」と書かれています。

ここで重要なのは、登録170人に対してアクティブが20〜30名という構造です。これは失敗ではなく、**緩い所属を許容する設計と整合的な数字**だと読めます。人が集まる言語だけ自然にゼミが立ち、集まらない言語は少人数のまま存続できます。ただし、この「人数偏り対策として意図的にそうした」という当事者の説明は公開情報からは確認できておらず、運用設計からの解釈です（要確認）。

### 2-2. 東京外国語大学ESS ── セクションを「言語」でなく「活動形式」で切る

[東京外国語大学ESSの紹介ページ](https://tufsess.wixsite.com/tufsess/introduction)では、ディベート・ディスカッション・ドラマ・I.C.S.・スピーチの5セクション制をとっています。部員は約130名（2013年11月現在の記載）。

運営面で参考になるのは次の2点です。

- **全体部会「ジェネミ」を毎週水曜の昼休みに113教室で開催**し、各セクションの情報を共有する。通常の活動は4限・5限・6限で、セクションごとに曜日・時間帯が異なる。
- **「部員は必ずいずれか一つのセクションに属します。ただし、どのセクションの活動にでてもいいんです」**と明記されている。所属は1つ、参加は自由という二段構えです。

セクションを言語ではなく活動形式（議論する／演じる／話す）で切っている点も示唆的です。言語で切ると話者数の少ない言語のセクションが即座に崩壊しますが、形式で切ればどの言語の人も同じセクションに入れます。

**要するにこうすればよい**：分科会は「立ち上げ自由・所属は1つ・参加はどこでも自由」の3点セットにし、**全体をつなぐ短い定例枠（週1回の昼休み15分でも可）を1つだけ必須にする**。これで、細分化しても全体が空中分解しません。

## 3. 多言語テーブル型：「常設言語＋変動言語」の二層構造にする

### 3-1. 筑波大学 Chat Events ── 実務モデルとして最も完成度が高い

[筑波大学スチューデントサポートセンターの告知](https://ssc.sec.tsukuba.ac.jp/archives/43764)は、多言語テーブル運営の設計図としてほぼそのまま流用できます。

| 項目 | 内容 |
|---|---|
| English Chat | 火曜・木曜 15:15〜16:30 |
| Multilingual Chat | 水曜・金曜 15:15〜16:30 |
| 場所 | スチューデント・コモンズ（第一エリア 1A棟203） |
| 常設テーブル | 日本語・フランス語・スペイン語は「基本的に毎回準備」 |
| 変動テーブル | 中国語・韓国語・ポルトガル語・アラビア語など（当日のスタッフ配置による） |
| 予約 | 不要 |
| スタッフ | 筑波大学の学生（留学生を含む） |
| 初心者対応 | ビギナーテーブルを設置。「全然話せなくてもOK」 |
| 位置づけ | 外国語を使って国際交流を楽しむ／深めるための会話体験イベント。語学を教える場ではない |

注目すべきは、**常設する言語と、その日のスタッフ次第で開く言語を公式に分けている**ことです。「母語話者を確保できない日はその言語のテーブルを開かない」と最初から宣言しておけば、当日の人員不足が運営の失敗になりません。

### 3-2. オンライン版 ── 大阪公立大学のVLT

対面の場所が確保できない場合、[大阪公立大学のVLT（バーチャル・ランゲージテーブル）](https://www.omu.ac.jp/las/coil/program/language-tables/)がオンライン多対多モデルの参考になります。

- Zoomで開催し、ブレイクアウトルームを管理する
- 1セッション1時間。①9:00〜10:00 ②11:00〜12:00 の2枠
- **実施時間の前後に10〜15分程度の打ち合わせと振り返り**を置く
- 開催は週5日（火〜土）のうち応相談。学生ボランティアは1人あたり週1〜2回程度のユニットを担当
- **1ユニット（1時間）を学生ボランティア15名程度で担当**する
- 相手校は米国の複数大学（2024年秋実績で21大学。バッファロー大学、ボストンカレッジ、ユタ大学など）
- 「英語力に自信がなくても大丈夫」と明記

前後の打ち合わせ・振り返りをセットにしている点は、そのまま真似する価値があります。

### 3-3. 名古屋学院大学 i-Lounge ── 「講師型」と「留学生型」を分離する

[名古屋学院大学のi-Lounge](https://www.ngu.jp/international/lounge/)は、2種類のテーブルを別運用しています。

| 種類 | 担当 | 形式 | 対象言語 |
|---|---|---|---|
| ランゲージ・テーブル | 常駐の外国人講師（ラーニング・アドバイザー） | 20分の短時間参加からビジネス英語・試験対策まで。無料・随時 | 主に英語 |
| 会話サロン | 留学生が講師役 | 決められた曜日と時間に毎週参加するスタイル。毎学期募集・無料 | 英語・スペイン語・ポルトガル語・中国語・韓国語・タイ語・インドネシア語など |

なお、関西外国語大学もIEPの枠内で英語・スペイン語・中国語・日本語の「ランゲージカフェ」を運営していますが、公式ページはアクセス制限がかかっており本文を取得できませんでした。頻度・曜日・テーブル分けなどの具体は**未確認**です（要確認）。

**要するにこうすればよい**：曜日と時間と場所を固定し、**確実に人が立つ2〜3言語だけを「常設」と宣言**し、残りは「その日のスタッフ次第」と最初から告知する。初心者テーブルを必ず1つ用意する。オンラインなら1時間1ユニット、前後に10〜15分の打合せと振り返りをセットにする。

## 4. 言語交換型：時間配分とマッチング方式を先に決める

大学が公開している言語交換プログラムには、そのまま使えるルールが揃っています。

| 大学 | マッチング方式 | 形式 | 頻度・時間 | 特記事項 |
|---|---|---|---|---|
| [明治大学](https://www.meiji.ac.jp/qfki0t000004xzci.html) | 事務局が割り当て | 1対1 または 1対2 を選択 | 週1回あたり60分を目安 | 共通言語（日本語または英語）と交換言語を分けて登録。登録9/20〜28、結果通知10/9 |
| [東京大学](https://www.u-tokyo.ac.jp/adm/inbound/ja/life-interact-ac-le.html) | 掲示板方式（自己選択） | 相手を自分で選んでメール申請 | 当事者間で調整 | 登録→2営業日以内に掲示板掲載→希望相手に申請。マッチング後48時間以内の連絡が必要 |
| [法政大学](https://www.global.hosei.ac.jp/on_campus/language_buddy/) | 事務局が海外協定校の学生と割り当て | 1対1のオンライン | 6週間以上、最低4回以上、1回約1時間 | **1回のうち英語30分・日本語30分**と明記。参加費無料、CEFR B1以上が目安 |
| [USC（米国）](https://dornsife.usc.edu/center-for-languages-and-cultures/home/students/language-exchange-program/) | センターがペアリング | 1対1 | 当事者が自由に設定 | 15言語対応。語学科目の履修不要。対象言語の母語話者なら学外者も参加可 |

ここから抽出できる実務的な要点は3つです。

1. **1対1か1対2かを選ばせる**。明治大学は、1対1はスケジュール調整が容易、1対2はマッチング成立の可能性が高い、と両者のトレードオフを明示しています。人数が偏る小規模サークルでは1対2を許容するだけでマッチング率が上がります。
2. **1回の長さを先に決める**。明治大学は「週1回60分」、法政大学は「約1時間、うち各言語30分ずつ」。**先に時間を半分に割っておく**ことが、片方の言語ばかり話される事故を防ぎます。時間を区切ったうえで会話中は訂正せず最後にまとめる、という進め方も紹介されていますが、これは個人ブログ由来の二次情報です（[参考](https://www.path-to-success.net/language-exchange)、要検証）。
3. **期待値を最初に下げる**。明治大学は「パートナーは語学の先生ではなく、本学の留学生です。語学スキルの向上より、異文化交流に重点を置いてください」と明記。東京大学も「パートナーは必ずしも母語話者とは限らない」と注記しています。

**要するにこうすればよい**：登録フォームに「学びたい言語」「教えられる言語」「共通言語」「1対1か1対2か」の4項目だけを置き、**1回60分・前半30分／後半30分・週1回**を推奨ルールとして最初から書く。マッチング後は48時間以内に連絡、という締切も付ける。人数が少ないうちは掲示板方式（自己選択）にすれば運営の手間はほぼゼロになります。

## 5. 母語話者をどう確保するか ── 答えは「学内の留学生を役割化する」

多言語サークルで最も詰まるのがここです。公開情報を横断すると、**学外のネイティブを雇う設計はほぼ存在せず、学内の留学生に役割を与える設計に集約されています**。

| ルート | 仕組み | 対価 | 出典 |
|---|---|---|---|
| イベントスタッフ化 | チャットイベントのスタッフに留学生を含める | 記載なし | [筑波大学](https://ssc.sec.tsukuba.ac.jp/archives/43764) |
| 講師役化 | 留学生が母国語の会話サロンの講師を務める | 記載なし（参加者は無料） | [名古屋学院大学](https://www.ngu.jp/international/lounge/) |
| バディ制度 | 全留学生に日本人学生のバディを配置し、週1回程度会う | 無償。条件を満たすと活動証明書を発行 | [関西学院大学 KGバディーズ](https://ciec.kwansei.ac.jp/interaction/support/buddies/) |
| バディ制度（無償型） | 短期留学生の修学・生活支援。帰国まで継続が原則。募集は年2回（2月・7月） | 謝金なし | [東京外国語大学](https://www.tufs.ac.jp/student/extraordinary/buddy.html) |
| チューター制度（有償） | 大学の制度として大学院生等を配置 | 有償・時間上限あり（下記） | [東京都立大学](https://www.ic.tmu.ac.jp/study_abroad/tutor.html)、[筑波大学](https://www.tsukuba.ac.jp/campuslife/support-international/tutor/) |
| 国別留学生会との連携 | 中国留学生会・韓国人留学生会・台湾留学生会などに直接声をかける | 交渉次第 | [明治大学 学生交流団体一覧](https://www.meiji.ac.jp/cip/student_support/student_association.html) |

### 5-1. 有償チューターは「別枠」と理解する

東京都立大学のチューター制度は、入学1年目の留学生に配置され、活動は**1か月16時間まで**、目安は**週1〜2日程度で2時間程度**、活動場所は原則学内で、日曜・祝日・長期休業期間は活動不可。チューターは留学生の専攻分野に関係のある大学院生から指導教員の推薦で選ばれ、半期ごとに規定の謝金が支払われます。そして「決して家庭教師やお世話係ではありません」と役割を明確に限定しています。

謝金の水準については、筑波大学のページに**「2024年10月活動分から謝金単価が1,100円に変更になりました」**と記載されています。ただし同ページに月あたりの上限時間の記載はありません。「時給1,000円・月15時間上限」という数字が流通していますが、これは大学によって異なるため、自分の大学の規程を必ず確認してください（要確認）。

いずれにせよ、**有償チューターは大学の制度であって、サークルが自前で回すものではありません**。サークルは無償のバディ／スタッフ側に立ち、有償チューターが必要な学生は大学の窓口に案内する、という線引きが安全です。

### 5-2. 見返りは「お金」ではなく「証明」と「居場所」

関西学院大学のKGバディーズは、メイン活動（1セメスターの間、週1回程度会う）に加えてオプション活動（短期プログラム日本語パートナー、日本語ボランティア、交換学生オリエンテーションサポートチーム）に参加すると活動証明書が発行されます。無償ボランティアを継続させる仕掛けとして参考になります。

**要するにこうすればよい**：ネイティブ探しを「個人的な人脈」で解こうとしない。①国際センターに「留学生にスタッフとして関わってもらえないか」と正面から相談する、②国別留学生会（中国/韓国/台湾など）に直接連絡する、③参加した留学生に**活動証明書や推薦状の発行**を大学と組んで用意する。この3つが再現性のあるルートです。

## 6. 大学の国際センターと組む ── 学生団体は「協働」できる

サークル単独でやるより、大学の部署と組むほうが圧倒的に楽です。実例が明確に公開されています。

| 大学 | 団体・仕組み | 内容 |
|---|---|---|
| [上智大学](https://piloti.sophia.ac.jp/?page_id=267) | GL-Net（Global Network） | 「グローバル教育センターと協同して活動を行っています」と公式に明記された学生ボランティア団体。留学生ウェルカムレセプション（毎年4月・9月）、ランチタイムサロン（毎月2回、主に6号館1階LLC）、日本文化紹介イベント、ワンデートリップを主催。Instagram @glnet_sophia |
| [立教大学](https://www.rikkyo.ac.jp/campuslife/support/international/international_exchange.html) | 国際交流ボランティア／グローバルラウンジ | 交換留学生の出迎え、住民登録引率、オリエンテーション補助、日本語授業サポート、バディプログラム。グローバルラウンジでは外国語で会話を楽しむWorld Café、Country Festaなどを実施。登録はRIKKYO PORTALから |
| [東北大学](https://www.insc.tohoku.ac.jp/japanese/global/exchange/student_organization/) | 8団体を大学公式サイトで一覧化 | GCS（留学アドバイジング）、TGLCA（メンター活動）、オアシス・アンバサダー（イベント企画運営）、ESA-net（交換留学生同窓会）、IPLANET（留学生サポート＋チューター制度）、TUSTEM（理系）、TUFSA（留学生協会）、TUMCA（イスラム文化・礼拝所やハラルフードの相談） |
| [Science Tokyo（旧東京工業大学）](https://www.titech.ac.jp/international-student-exchange/students/abroad/international-exchange) | ラウンジ＋チューター＋学生団体の3点セット | 留学生ラウンジ（大岡山キャンパス西1号館1階）、Taki Plaza Gardener（学生組織による企画運営）、SAGE／S-TISA（留学生会）／FLAP |

東北大学の一覧は特に有用です。**8団体が「留学準備支援」「留学生の生活支援」「文化・宗教別コミュニティ」「理系特化」と役割を分担している**ので、自分のサークルが何を担当し、何を他団体に譲るかを考える際のチェックリストとして使えます。また、東北大学のIPLANETは学生団体でありながら言語チューター制度を自前で持っており、学生団体でもここまでできるという実例になります。

### 6-1. 継続している団体に共通する「3層構造」

[早稲田大学国際学生友好会（WIC）](https://www.waseda.jp/inst/weekly/circleguide/detail/?id=3044&lng=en)は1956年設立、部員120人（うち留学生30人）。毎週水曜に「日本教室」を開き、月〜金の2〜5限は15号館ラウンジで活動し、月1回以上のイベント・旅行・ツアーを実施しています。授業ボランティアや区役所同行といった生活支援も行っています。

WIC、筑波大学（週4日の固定枠）、上智GL-Net（月2回のランチタイムサロン＋学期頭のウェルカムレセプション）、名古屋学院大学（常駐ラウンジ＋週次会話サロン）を並べると、**「常設の居場所」「週次の固定枠」「月次のイベント」の3層**が共通しています。これは公開情報からの観察であり、各団体が意図してそう設計したと明言しているわけではありません。

なお、こうした活動が解こうとしている課題は具体的です。[静岡産業大学の国際交流会](https://www.ssu.ac.jp/campuslife/club-circle/bunka/07/)は「日本人と留学生との交流をもっと深めたい」という動機から2011年に藤枝キャンパスで日本語サークルとして発足し、2013年から国際交流会として活動。2020年には磐田キャンパスにも留学生交流サークルが設立されました。部員は16名と5名の小規模で、中国・ベトナム・ミャンマー・インドネシア・ネパールの学生が参加し、ゲームや料理教室、スポーツ、各国の宗教・文化の学習を行っています。**20人未満でも成立する**という実例です。

**要するにこうすればよい**：立ち上げの最初の1週間で、自分の大学の国際センター（留学生支援室）に足を運び、「留学生向けの既存イベントを手伝わせてほしい」と申し出る。ゼロからイベントを作るより、既存のウェルカムレセプションやオリエンテーションに入り込むほうが、留学生とのつながりが一気に手に入ります。上智GL-Netのランチタイムサロン（月2回）のような**低コストの定期枠を1つ持たせてもらう**のが最初の目標として現実的です。

## 7. 学祭・年次イベント：語劇という完成フォーマット

多言語サークルが学祭で何をやるか、という問いには既に完成した答えがあります。

[神戸市外国語大学の語劇祭](https://www.kobe-cufs.ac.jp/campuslife/event/gogekisai.html)は70年以上の伝統を持ち、第75回は2025年10月25日・26日に新開地アートひろばで開催されました。英米・第2部英米、ロシア、中国、イスパニアの**4劇団がそれぞれの言語で上演**し、「全ての公演に日本語字幕がありますので、言語の知識に関わらずお楽しみいただけます」と明記されています。運営面では「演目選びから、衣装、照明、音響効果、舞台装置、そして語劇ならではの日本語訳の字幕作成にいたるまで、全て学生が担当します」とされ、教員は発音指導などで協力します。

同様に、東京外国語大学の外語祭では26言語の語劇が上演され、1900年以来の歴史を持つと[大学プレスセンターの記事](https://www.u-presscenter.jp/article/118084)で紹介されています（本文未取得のため詳細は要確認）。

また、[神田外語大学のサークル一覧](https://www.kandagaigo.ac.jp/kuis/main/campuslife/circle/)には、耕音會（中国古典楽器・二胡）、无乐不作〜ウルブス（中国語専攻生が主体）、ドントリー･ラムタイ愛好会（タイの伝統楽器と舞踊）、KUISトルンアンサンブル愛好会（ベトナムの伝統楽器トルン）、ガムラン愛好会ムルデカ（インドネシアのガムランと舞踊）、くいすにほんごくらぶ（地域在住外国人への日本語学習支援）など、**「言語×文化実技」型の少人数サークル**が並んでいます。英語以外の言語コミュニティを作る際、「その言語を勉強する会」より「その言語圏の楽器・料理・演劇をやる会」のほうが人が集まりやすい、という実例です。

**要するにこうすればよい**：学祭企画は「多言語スピーチ大会」より**語劇（短編でよい）**が強い。日本語字幕を必ず付ければ、その言語を知らない来場者も客層に入り、宣伝効果が段違いになります。人数が足りないなら、10分の寸劇を2言語分だけでも成立します。

## 8. 立ち上げ実務：公認要件は大学差が非常に大きい

| 大学 | 主な要件 |
|---|---|
| [早稲田大学](https://www.waseda.jp/inst/student/circle/howto) | 早大生のみで**21人以上**かつ**2学部以上**にまたがる構成員／設立予定のサークル名で**1年以上の活動実績**／1年間以上の領収証付き会計報告（サークル名宛・使途明記・発行者情報入り）／会長・幹事長・副幹事長・会計を各1名配置。サークル内での三役兼任は不可、他の公認サークル三役との兼任も不可、三役のうち1名以上は3年生以下。**会長は専任教員等の大学職員**が務め、会長の兼務は2団体まで。申請にはサークル講習会への参加が必須 |
| [信州大学](https://www.shinshu-u.ac.jp/campus_life/studentsupport/circle/lend.html) | 本学の学生**5名以上**＋顧問教員（本文未取得、検索結果ベース／要確認） |
| 明治学院大学 | まず「設立準備団体」として申請し、1年間活動した後に改めて公認申請（要確認） |
| 京都芸術大学 | サークル代表者が自分で顧問を探す必要がある（要確認） |

一般的に、必要書類は団体設立届・規約・代表者を含む名簿の3点セットであることが多いですが、大学ごとに大きく違うため、**学生課／学生生活課のサイトで自分の大学の要件を必ず一次確認してください**。

### 最初の1年のロードマップ（上記の実例から逆算した進め方）

| 時期 | やること | 参考にした実例 |
|---|---|---|
| 第1〜2週 | 国際センター／留学生支援室に相談。既存イベントの手伝いに入る | 上智GL-Net、立教 |
| 第3〜4週 | 曜日・時間・場所を固定した週1回の会話テーブルを開始。常設は2〜3言語のみ宣言 | 筑波大 Chat Events |
| 1〜2か月目 | 国別留学生会に接触し、スタッフ役の留学生を確保 | 明治大 学生交流団体一覧 |
| 2〜3か月目 | 希望者向けに言語交換ペアのマッチングを開始（掲示板方式で運営コストを抑える） | 東大 言語交換プログラム |
| 3か月目〜 | 分科会（ゼミ）の自由立ち上げを解禁。全体をつなぐ月1回の定例会を設置 | 東大語学愛好会、東京外大ESS |
| 半年〜1年 | 学祭で短編語劇（日本語字幕付き）。並行して会計記録と名簿を整え公認申請へ | 神戸市外大、早稲田の公認要件 |

なお、継続の鍵として「活動が定期的にあること」「活動以外でもメンバー同士がコミュニケーションを取ること」を挙げ、「企画がひとりよがり、幹部よがりだとメンバーが離れていく」と指摘する個人の体験談もあります（[note](https://note.com/tam_irish/n/nbcdf8ee3b12e)）。これは一次情報ではないため、参考程度に扱ってください。

**要するにこうすればよい**：公認は「後から取るもの」と割り切る。早稲田のように1年間の活動実績と領収証付き会計報告を求める大学がある以上、**初日から領収証を封筒にためて、活動日誌と参加者名簿をスプレッドシートに残す**。この2つを1年やるだけで、公認申請の作業量が劇的に下がります。

## 9. 参考になる全国規模・学外の団体

学内だけで完結させない選択肢もあります。[日本国際学生協会（I.S.A.）](https://www.isa-japan.org/)は約200人の学生が4つの拠点に分かれて活動し、24か国への送り出しと海外学生の受け入れを行っています。源流は1934年に遡り、国際学生会議（ISC）も関連事業として運営されています。

また、[UT-BASEの「国際交流・語学」カテゴリ](https://ut-base.info/circle_categories/6)には、日米学生会議、日英学生会議、日仏学生フォーラム、日露学生会議、日中学生会議、京論壇（北京大と東大の学術交流）、HUAP Tokyo、MIS（日本・ASEAN学生）、TGIF（留学生と非留学生の交流促進）、UTDS（英語即興ディベート）、GERNE（オンライン国際交流イベント）などが並んでいます。**二国間フォーラム型**は、言語別分科会が成立しない規模でも「相手国1つ」に絞れば成立するという意味で、有力な代替モデルです。

**要するにこうすればよい**：自分の大学に人が集まらないなら、無理に多言語を維持せず「1か国×深い交流」に振るか、全国団体の支部として動くほうが継続しやすい。
