**公開 URL: <https://kazuyan38.github.io/languageclub/app/>**

部員に配るのはこの URL だけで足ります。インストールもログインも会員登録も不要です。

> **GitHub Pages をまだ有効にしていない場合**
>
> 1. GitHub のリポジトリで **Settings → Pages** を開く
> 2. Source を **Deploy from a branch**、Branch を **main** と **/ (root)** にして Save
> 3. 1〜2 分待ってから上の URL を開く(表示されないときは Ctrl+Shift+R で再読み込み)

## 何をするアプリか

お手本の英文を聞いて、そのまま声に出す。**パソコンの「耳」がどこまで聞き取れたか**を、その場で単語ごとに見せます。

設計の目的はこの一行だけです。

> 新歓ブースの共有 PC で、初めて触る 1 年生が 3 分使って、一度も固まらず、一度も意味不明なエラーを見ずに、英語を 15 回声に出して帰れること。

**このアプリが測れるのは「Google の音声認識に伝わったか」であって、発音の良し悪しではありません。**画面に出るのは「伝わり度」と「◯語中◯語が伝わりました」で、点数の数値は既定では表示しません。うまく伝わらなかったときも「もう一度ためしてみましょう」と出るだけです。

位置づけは「英会話が上達するアプリ」ではなく、**サークル活動の補助輪 — 英語を声に出す回数を増やす装置 + 通じにくい語の発見器**です。部員どうしの点数ランキングは意図的に作っていません(マイクの品質で点数がかなり変わるうえ、序列をつけると初級者が離脱するため)。

## 動作環境

| 環境 | 可否 | 備考 |
|---|---|---|
| **パソコンの Google Chrome** | ◎ 推奨 | Windows / Mac のどちらでも |
| Android の Google Chrome | ○ 使える | パソコンのほうが安定します。イヤホン推奨 |
| iPhone / iPad の Safari | △ 使えるが不安定なことがある | マイクが止まらない・結果が返らないなど、他の環境より不具合が出やすい。イヤホン推奨 |
| iPhone / iPad の Chrome・Firefox・Edge | ✕ 使えません | iOS では Safari 以外のブラウザに音声認識のしくみが無い(Apple 側の制約) |
| パソコンの Firefox / Safari / Microsoft Edge | ✕ 使えません | 音声認識に対応していません |

- **インターネット接続が必須です。** Chrome の音声認識は Google のサーバーが文字起こしをするため、オフラインでは使えません。
- マイクが必要です。**イヤホンかヘッドセットの使用を強くおすすめします。**スピーカーだと、お手本の読み上げをマイクが拾ってしまい、何も話していないのに満点になることがあります。
- 教材を読む・お手本を聞く・設定を変える、といった操作は上記以外のブラウザでも動きます(音声認識だけが使えません)。

## プライバシー

- **話した声は Google の音声認識サーバーに送られます。**これは Chrome の音声認識の仕組み上どうしても必要です。アプリの初回起動時に、この点への同意画面を出しています。
- **録音データはこのアプリには一切保存されません。**文字起こしの結果だけを使い、音声そのものは保持しません。
- **学習の記録(進捗・苦手な語・練習履歴)は、使っている端末のブラウザの中(localStorage)だけに保存されます。**サーバーへの送信も、部員間での共有も、アカウント連携もありません。
- 記録は「きろく」画面の **記録をすべて消す** からいつでも全部消せます。
- 共有パソコンで使うときは、下の「新歓ブースでの使い方」を読んでください。

## 使い方(3 ステップ)

1. **公開 URL を Chrome で開く。**初回だけ 3 枚の説明が出るので、読んでマイクの使用を許可します。
2. **カテゴリを選ぶ。**「自己紹介」「キャンパスで」「学食・カフェで」など 6 カテゴリ × 6 フレーズが入っています。
3. **大きなボタンを押して、お手本のあとに同じ文を声に出す。**結果が出たら「もう一度」を押して繰り返します。1 フレーズにつき 3 回まで試せて、**80 点以上が 2 回でクリア**です(1 回の聞き間違いで落とされず、まぐれ 1 回でもクリアにならない設定です)。

キーボードだけでも操作できます。`Space` で「聞いて話す / 話し終わり」、`R` でもう一度、`N` で次のフレーズ、`Esc` で全停止です。

## 教材(フレーズ)の増やし方

### 方法 1: アプリの中で貼り付ける(プログラミング不要・おすすめ)

アプリのホーム画面いちばん下の **「自分でフレーズを追加する」** を開き、テキストエリアに次のように貼り付けて「追加する」を押すだけです。

```text
# 学祭でつかう英語
Would you like to try our curry? | カレーはいかがですか？
It is three hundred yen. | 300 円です。
```

- 1 行につき 1 フレーズ。英文と日本語訳を `|` で区切ります(全角の `｜` でも大丈夫です)。
- 1 行目に `# カテゴリ名` と書くとカテゴリに名前が付きます。
- 日本語訳は省略できます。空行と `//` で始まる行は無視されます。
- 作ったカテゴリは **書き出し** ボタンで文字列にできるので、LINE で他の部員に渡して **読み込み** してもらえます。
- ここで追加した教材は、追加した端末の中だけに保存されます。全員に配りたいときは方法 2 を使ってください。

### 方法 2: `data/decks.js` を編集する(全員に配りたいとき)

[`data/decks.js`](./data/decks.js) が教材の本体です。中身は JSON とほぼ同じ配列なので、書式さえ真似すれば壊れにくくなっています。

```js
{ id: 'intro-07',
  text: "I like reading books in English.",
  accept: ["I like to read books in English."],
  ja: '英語で本を読むのが好きです。',
  note: 'reading の r を落とさないように。',
  focus: ['r-l'] },
```

**オーサリングのルール(7 項目)**

1. **文末に必ず終止符(`.` や `?`)を打つ。**無いと読み上げの抑揚が平坦になり、次の文とつながって聞こえます。
2. **数字はできるだけ書かない。**書く場合は数詞で書き、`accept` にアラビア数字版も入れてください(認識器は "three hundred fifty" を `350` と書き起こします)。
3. **固有名詞(人名・大学名)は避ける。**`Waseda` が `waste a` になるなど、話し手の発音と関係なく落ちます。`Tokyo` のような超高頻度語だけ許可します。
4. **1 フレーズは 6〜14 語。**長いと一息で言い切れず、途中の無音で録音が切れてしまいます。
5. `accept` には **「言い方が違うだけで通じ方が同じ言い換え」だけ**を入れる。**語順違いは入れないでください。**
6. `focus` は既定の 7 タグ(`th` / `r-l` / `v-b` / `f-h` / `vowel-length` / `ending-vowel` / `linking`)以外を勝手に増やさない。苦手な音の集計に使っています。
7. **フレーズを足したら [`test/test.html`](./test/test.html) をダブルクリックして開く。**id の重複・語数オーバー・終止符の付け忘れは、そこで赤く落ちます。

## 開発・メンテナンス向け

### ファイル構成

| パス | 中身 |
|---|---|
| `index.html` | エントリ。`<script>` の並び順がそのまま依存関係です |
| `css/tokens.css` | 色・余白・文字サイズの定義(CSS 変数)とリセット |
| `css/style.css` | レイアウトと見た目。トークン変数以外の色は書きません |
| `data/decks.js` | **教材。部員が触るのは基本ここだけ** |
| `js/01-util.js` | 小道具(DOM 生成・トースト・ログ)と日本語文言 `LC.msg` |
| `js/02-store.js` | localStorage の抽象化・環境判定・設定 |
| `js/03-text.js` | 正規化 / 文字列類似度 / 単語アライメント / 採点 |
| `js/04-catalog.js` | 教材の検証・自作デッキ・学習記録 |
| `js/05-speech.js` | 読み上げ(TTS)と音声認識(ASR)のラッパ |
| `js/06-session.js` | 練習の進行管理。読み上げと録音の排他制御 |
| `js/07-ui.js` | 結果表示・エラーパネル・レベルメーターの共通部品 |
| `js/08-screen-practice.js` | 練習画面 |
| `js/09-screens.js` | ホーム / きろく / せってい / 使い方 / 自作デッキ など |
| `js/99-app.js` | 起動・画面遷移(ハッシュルーティング)・全域エラー処理 |
| `test/test.html` `test/cases.js` | 自己テスト |

### 依存の向き(一方向。逆流させない)

```text
01-util → 02-store → data/decks.js → 03-text → 04-catalog
        → 05-speech → 06-session → 07-ui → 08/09-screen → 99-app
```

右のファイルが左のファイルを呼ぶのは自由ですが、**左が右を呼んではいけません。**すべて `window.LC` の下にぶら下がる classic script で、ビルドは不要です。

### 触ってよい場所 / 慎重に触る場所

| | 場所 | ひとこと |
|---|---|---|
| **触ってよい** | `data/decks.js` | 教材。上のオーサリングルールを守ればいくら足しても大丈夫です |
| **触ってよい** | `js/01-util.js` の `LC.msg` | 画面に出る日本語はすべてここに集めてあります |
| **触ってよい** | `css/tokens.css` | 色・余白・文字サイズ。ここだけで見た目の印象は変えられます |
| **慎重に** | `js/06-session.js` | 読み上げと録音を**絶対に同時に動かさない**ための唯一の場所です |
| **慎重に** | `js/05-speech.js` | ブラウザの音声 API の癖(読み上げ終了イベントが来ない、権限拒否時に例外が飛ぶ等)を全部ここで吸収しています |

**壊してはいけない約束**

- `type="module"` / `fetch()` / 動的 `import()` / 外部 CDN・外部フォントを使わない(ダブルクリックで開けなくなります)
- `continuous = true` と、`onend` の中で `start()` を呼ぶコードを書かない(タブが固まる最大の原因です)
- `localStorage` に触るのは `js/02-store.js` だけ
- `speechSynthesis` / `SpeechRecognition` に触るのは `js/05-speech.js` だけ
- 画面の言い方を崩さない。点数は「伝わり度」、結果は「◯語中◯語が伝わりました」、うまくいかなかったときは「もう一度ためしてみましょう」。発音の良し悪しを判定しているかのような言葉は使わない

### テストの走らせ方

[`test/test.html`](./test/test.html) を **エクスプローラーやファインダーからダブルクリックするだけ**です。サーバーもビルドも要りません。開くと最上部に大きく `合格 ◯ / 失敗 ◯` が出ます。

テストしているのは画面に触らない部分だけです。

- 採点(仕様どおりの点数とバンドが出るか)
- 正規化(縮約形・数字・英米綴り・フィラー)
- 単語アライメント、発音ヒント
- 教材の検証(**同梱デッキ全部を舐めます**)と貼り付け解析
- 設定の矯正、localStorage の読み書き・破損復旧

読み上げと音声認識は自動テストしません。**リリース前に必ず、実機の Chrome で 1 デッキ通しで練習してください。**

### ローカルで http として動かす

`file://`(ダブルクリック)でも起動はしますが、音声認識が動かないことがあります。手元で本番と同じ条件を試したいときは、リポジトリのルートで簡易サーバーを立ててください。

```sh
# Python 3 が入っていれば
python -m http.server 8000
# → http://localhost:8000/app/ を Chrome で開く

# Node.js 派なら
npx http-server -p 8000
```

`localhost` は安全なオリジンとして扱われるため、マイクの許可も本番と同じように動きます。

## 既知の制約

- **オフラインでは音声認識が使えません。**Web Speech API の仕組み上どうしようもない部分です。教材を読む・お手本を聞く(端末内蔵の音声の場合)はオフラインでも動きます。
- **`file://`(ファイルをダブルクリック)では音声認識が動かないことがあります。**アプリ自体は起動して教材も読めますが、マイクが取れなかった場合は公開 URL への案内が出ます。
- **点数は「機械に伝わったか」であって、発音の良し悪しではありません。**マイクの品質や周囲の騒音でも変わります。保証できるのは「同じ人が同じ環境で繰り返したときの相対的な傾向」だけです。だからこそ、単発の点数ではなく **通じにくい語のランキング**を主要な出力に置いています。
- うまく拾えなかったときは、結果画面の **「うまく拾えなかった(この回を記録から除く)」** で記録から外せます。機械のせいなのか自分のせいなのか分からない、という状況を残さないための拒否権です。
- 動かないときは **「使い方と困ったとき」画面の「診断結果をコピー」** を押して、その内容をメンテ担当に送ってください。原因の切り分けがそれだけで終わります。

## 新歓ブースでの使い方

共有パソコンで使うときは、次の URL をブックマークしてください。

```text
https://kazuyan38.github.io/languageclub/app/?demo=1#/
```

`?demo=1` を付けて開くと **体験モード** で起動し、学習記録が端末に一切保存されません。ヘッダーに「体験モード」のバッジが出続けるので、来場者にも安心してもらえます。

当日の運用のコツ。

- **イヤホンを 1 セット用意する。**スピーカー再生だと読み上げをマイクが拾ってしまいます。
- **できるだけ静かな角に置く。**周囲が騒がしいと認識が通りません。
- 最初に触ってもらうのは **「自己紹介」の 1 フレーズ目**が無難です。短くてクリアしやすい文にしてあります。
- 事前に一度、当日と同じパソコン・同じ Wi-Fi で通しで動かしておいてください。当日「動かない」を出さないことが、このアプリの最優先事項です。
